出典：シラバス 授業概要

シラバスでは、週ごとのテーマについてコードを実行し、結果を確認できることを求めています。分析手法の説明を理解することと、実際の出力を確かめることを結びつけていきます。そのために、はじめはコンピュータやネットワーク、実行環境についても学びます。

申請から利用までの5ステップ

  1. 自分の GitHubアカウントを準備する。
  2. 大学メール・在学を示す書類を準備する。
  3. GitHub Educationの学生申請を送信する。
  4. 承認後、Copilot Studentを有効にする。
  5. VS Codeで同じアカウントにサインインし、確認する。

学生認証の承認と、Copilotの有効化は別の手続きです。

出典：申請マニュアル 0（確認・更新日：2026-09-28）

全体は五つの段階です。アカウントを準備し、大学メールと在学を示す書類をそろえて、学生申請を送ります。承認されたら、コパイロット・スチューデントを有効にし、同じアカウントでブイエス・コードにサインインします。学生認証に通ることと、コパイロットを有効にすることは別の手続きです。審査にかかる時間は一律ではなく、承認後の特典反映にも数日かかる場合があるため、早めに申請しましょう。

大学メールと在学を示す書類を準備する

  • 自分専用の GitHubアカウント。
  • 大学メールと、その受信トレイへのアクセス。
  • 現在の在学を示す書類：学生証・時間割・在学証明書など。
  • パソコン・VS Code・安定したインターネット接続。
  • 2要素認証に使うスマートフォン等。

書類は 氏名・学校名・在学を確認できる日付や有効期限が読めるもの。
必要な情報が欠けないよう、鮮明に撮影します。

出典：申請マニュアル 1

大学から付与されたメールアドレスだけでなく、受信トレイを開けることを確認します。在学を示す書類は、氏名、学校名、現在の在学を確認できる日付や有効期限が読み取れるものを用意してください。学生証だけでは現在の在学を確認しにくい場合は、時間割や在学証明書なども準備します。写真は必要な情報が欠けないよう、文字が読める明るさで撮影します。日付や氏名を書き換えてはいけません。提出方法は実際の申請画面に従います。

アカウントを準備し、大学メールを確認する

  1. アカウントがあれば そのまま使う。
    初めてなら GitHubのアカウント作成ページで登録する。
  2. Settings → Emails で大学メールを追加する。
  3. 大学Gmailに届くメールで Verify 等の確認を完了する。
  • Usernameは実名でなくてよい。学籍番号等を避ける。
  • 申請する氏名は、提出書類の表記とそろえる。
  • Usernameと公開プロフィールの Nameは別。不安があれば相談する。

出典：申請マニュアル 2.1〜2.3

すでにギットハブのアカウントがある人は、新しく作らず、そのアカウントにログインしてください。初めての人は、リンク先から登録し、メールの確認まで終えます。設定のイーメールズで大学メールを追加し、大学の受信トレイに届いたメールで確認します。卒業後も使える個人メールを同じアカウントに追加しておくことも推奨されています。メールを公開プロフィールに表示する必要はありません。ユーザーネームは実名でなくて構いませんが、申請する氏名は証明書とそろえます。公開名とユーザーネームは別で、公開名の設定に不安があれば相談してください。

2要素認証でアカウントを守る

申請前の設定を 推奨します。必須の案内が出た場合は従ってください。

  1. Settings → Password and authentication を開く。
  2. Two-factor authentication の設定を開始する。
  3. 認証アプリを使う場合は、QRコードを読み取り、確認コードを入力する。
  4. Recovery codes（復旧コード） を保存する。

復旧コードは 人に見せず、安全に保管してください。
設定に迷ったら、担当教員に相談しましょう。

出典：申請マニュアル 2.4

アカウントを守るため、申請前に二要素認証を設定することを推奨します。ギットハブから必須とする案内が出た場合は、その案内に従ってください。認証アプリを使う場合は、表示されたキューアールコードを読み取り、アプリの確認コードを入力します。最後に発行される復旧コードは、スマートフォンを使えなくなったときに備えて、安全に保管してください。パスキーは生体認証やピンなどを使う認証方法で、単にスマートフォンでコードを読み取ることだけを指すものではありません。迷ったら無理に認証方法を増やさず、担当教員に相談しましょう。

GitHub Educationに学生申請する

  1. Education benefits を開く。
  2. Start an application から、学生として申請する。
  3. 大学名・メールなどを入力し、求められた在学証明を提出する。
  4. 内容を確認し、Submit application 等で送信する。
  5. 登録メールとEducation benefits で結果を確認する。

追加確認・不承認の場合は、通知された理由と不足点を確認します。
大学が見つからなくても、別の大学を選ばないでください。

出典：申請マニュアル 3・5

申請に使うアカウントでログインして、エデュケーション・ベネフィッツを開きます。学生として申請を開始し、大学名やメールアドレスなど、求められた項目を正確に入力します。在学証明を求められたら、指定の方法で提出し、内容を確認して送信してください。結果は登録メールと設定ページで確認します。追加確認や不承認の通知が来た場合は、その理由を読んで不足点を修正します。大学名やメールドメインが認識されない場合は、事実と異なる情報で進めず、担当教員やサポートに相談します。

学生認証が承認されたら、もう一度エデュケーション・ベネフィッツを開きます。学生と教員向けの無料リソースの欄から、ラーン・モアを選び、案内に従ってコパイロット・スチューデントを有効にします。最後に、コパイロット側の設定ページで学生向け特典が適用されていることを確認してください。ギットハブ・プロと表示されるだけでは確認になりません。無料トライアルやカード入力、購入画面が出た場合は契約せずに止めます。特典の反映を待ち、それでも解決しなければギットハブ・サポートに相談してください。

学習用データの扱いと、入力内容の外部送信は別です。
入力・添付する情報を確認してから利用します。

出典：申請マニュアル 4.2（確認・更新日：2026-09-28）

ここはデータの扱いについての確認です。申請マニュアルでは、コパイロット・スチューデントは、2026年4月24日からの個人向けプランの学習用データ利用変更の対象外と説明されています。ただし、入力した情報が外部に送信されないという意味ではありません。承認待ちなどでコパイロット・フリーを使う場合は、設定ページを確認し、学習用データの利用を許可する設定が表示されれば、ディセーブルドにすることを推奨しています。どのプランでも、送信する内容を自分で確認してください。

AIを学習に使うときの3つの約束

  1. 送信する情報を確認する
    パスワード・APIキー・学生証・他人の個人情報・未公開データを入力しない。
  2. 変更・実行の内容を確認する
    AIの説明やコードが正しいとは限らない。理解せずに承認しない。
  3. 自分で理解することを優先する
    完成した解答をそのまま提出せず、説明やヒントを求めて確認する。

課題ごとのAI利用条件は、担当教員の指示を優先します。

出典：申請マニュアル 4.2

利用するときは三つのことを守りましょう。一つ目は、送信する情報の確認です。パスワードやエーピーアイキー、学生証、他人の個人情報、未公開の研究や業務のデータを入力したり添付したりしないでください。学生証を学生認証の申請画面に提出することと、エーアイに添付することは別です。二つ目は、ファイルの変更やコマンドの実行を、理解しないまま承認しないことです。三つ目は、完成した答えをそのまま提出するのではなく、説明やヒントを求めて自分で確認することです。課題ごとの利用条件は、担当教員の指示を優先してください。

VS Codeで同じアカウントにサインイン

  1. VS Codeを開く。
  2. 下部のCopilotアイコンから Use AI Features 等で設定を開始する。
  3. 学生認証を受けたGitHubアカウントでサインインする。
  4. ブラウザでの認証を終え、VS Codeに戻る。
  5. 必要な公式拡張機能は、案内に従って有効化・インストールする。

拡張機能を検索して追加する場合は、発行元がGitHubかを確認します。
WSL2を使う場合も、Windows側のVS Codeで授業用フォルダを開きます。

出典：申請マニュアル 4.3（確認・更新日：2026-09-28）

ブイエス・コードを開き、画面下部のコパイロットのアイコンから、ユーズ・エーアイ・フィーチャーズなどの案内に沿って設定を開始します。サインインには、学生認証を受けたのと同じギットハブのアカウントを使ってください。ブラウザで認証が終わったら、ブイエス・コードに戻ります。公式拡張機能の有効化やインストールを求められたら、画面の案内に従います。自分で検索する場合は発行元がギットハブかを確認し、重複して追加しないようにします。ダブリューエスエル・ツーを使う場合も、ウィンドウズ側のブイエス・コードから授業用フォルダを開きます。申請のために別の開発環境へ移る必要はありません。

チャットに「説明だけ」を頼んでみる

Copilotのチャットを開き、次のように質問します。

Pythonのprint(“Hello”)は何をする命令ですか。
プログラミング初心者向けに、日本語で短く説明してください。
ファイルの変更やコマンドの実行はせず、説明だけしてください。

返答が出れば、チャットの接続を確認できます。
実行の確認が出ても承認せず、説明だけを求め直してください。

出典：申請マニュアル 4.4（チャットの確認）

接続の確認には、スライドにある質問を使います。パイソンのプリントでハローと表示する命令について、初心者向けに短く説明するよう頼んでいます。さらに、ファイルの変更やコマンドの実行はせず、説明だけを求めています。返答が出れば、チャットの接続を確認できます。この確認のために、ファイル変更やコマンド実行を承認する必要はありません。もし実行の確認が出たら承認せず、説明だけを求め直してください。

コード補完も確認する

練習用の copilot_check.py を作り、次の内容を入力します。

numbers = [1, 2, 3, 4, 5]
# numbersの合計を計算して表示する
  • その下の行で少し待ち、薄い文字の候補が出るか確認する。
  • 候補は常に表示されるとは限らない。
  • 出ないときは、Copilotの有効・無効とサインイン状態を確認する。

出典：申請マニュアル 4.4（コード補完の確認）

チャットとは別に、コード補完も確認します。練習用のコパイロット・チェックというパイソンファイルを作り、スライドの二行を入力してください。一行目は数値のリスト、二行目はその合計を計算して表示するというコメントです。その下の行で少し待ちます。続きの候補が薄い文字で表示されれば、コード補完が利用できています。ただし、候補は常に出るとは限りません。表示されない場合は、コパイロットが有効か、正しいアカウントでサインインしているかを確認してください。

プラン コード補完 チャット等
Copilot Student 無制限 GitHub AI Creditsによる利用枠あり
Copilot Free 月2,000回まで 利用枠あり

  • 上限に達しても、追加予算や有料契約を設定しない。

Educationの有効期限・更新案内を確認し、必要な場合に再申請します。

出典：申請マニュアル 0・4.5（確認・更新日：2026-09-28）

マニュアルの確認日時点では、学生向けプランのコード補完は無制限ですが、チャットやエージェントにはギットハブ・エーアイ・クレジットによる利用枠があります。長い会話や複数の処理では消費が増えるため、質問一回で一定量とは限りません。モデルはオートによる自動選択です。承認前にも使えるフリープランは、コード補完が月二千回までで、チャットなどにも枠があります。上限に達しても有料契約や追加予算で解決せず、エーアイを使わない作業を進め、必要なら相談してください。すでに有料契約などがある人は、その課金設定も確認します。学生資格の毎月の再評価は、毎月初めから申請し直す意味ではありません。有効期限と更新案内を確認してください。

出典：申請マニュアル 5

困ったときは、どの段階で止まったかを整理します。メールが届かない場合は、入力や迷惑メール、受信状態を確認します。学生認証が通らない場合は、通知された理由と証明書の内容を見直します。大学が認識されない場合は、正式名称、公式サイト、メールドメインを確認して、担当教員や学内窓口、サポートに相談してください。承認後もフリーのままなら有効化と反映待ちを確認します。ブイエス・コードだけで使えない場合はアカウントを確認し、必要ならサインインし直します。複数アカウントの場合は拡張機能が使うアカウント設定も確認します。相談時の画像にメールアドレス、学生証、認証コードなどが写らないようにしましょう。

準備の確認：どこまでできましたか

  • Educationの学生認証が承認されている。
  • Copilot側で学生向け特典が有効になっている。
  • VS Codeで同じGitHubアカウントにサインインしている。
  • チャットの応答を確認し、コード補完の表示・設定も確認した。

未完了でも、アカウントを作り直したり、有料契約をしたりせず、
どこで止まったかを担当教員に伝えてください。

出典：申請マニュアル 冒頭・4.4

最後に、準備がどこまで進んだか確認しましょう。学生認証は承認されましたか。コパイロット側の学生向け特典は有効ですか。ブイエス・コードには同じアカウントでサインインしていますか。チャットの応答と、コード補完の表示や設定を確認できましたか。完了していない項目があっても、新しいアカウントを作り直したり、有料契約をしたりする必要はありません。承認が間に合わない場合も含め、止まった段階を担当教員に伝えてください。
