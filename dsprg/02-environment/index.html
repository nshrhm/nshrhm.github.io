初回の準備と、毎回の起動を分ける

操作の流れ

初回だけ 次回から毎回
配布ファイルを取得する Start.cmd で開く
Windows・WSLを準備する プログラムを書く・保存する
Install.ps1 でUbuntuを取り込む タスク／Notebookの▶で実行する
VS Code接続・拡張機能を確認する 保存して終了する

毎回のインポートは不要です。

導入はInstall.ps1、普段の起動はStart.cmdを使います。

出典：マニュアル「初回だけ行うこと」「次の授業から行うこと」

初回だけ、ダウンロードや取り込み、拡張機能の確認を行います。次の授業からは、スタート・シーエムディーで授業用の画面を開きます。 大きなファイルのダウンロードを早めに始めます。待っている間にパソコンとダブリューエスエルの準備を確認し、ダウンロードが終わったら配置へ戻る進め方にします。

照合と取り込みが終わるまで待つ

Windows｜Install.ps1の実行画面

スクリプトが順に行います。

  1. tarの SHA-256 を教員の指定値と照合する。
  2. DSProg2026 という名前でWSL2へ取り込む。
  • 長いハッシュ値を自分で入力する必要はありません。
  • 同じ名前・導入先がある場合は、上書きせず停止します。
  • エラーが出たら、画面をそのまま教員に見せます。
処理中は画面を閉じない。停止したら削除・再実行を繰り返さず相談。

出典：マニュアル「照合とインポートが終わるまで、画面を閉じない」

はじめに、配布されたタールが指定のファイルと一致するかを確かめます。その後、授業用の名前でウブントゥを取り込みます。長いハッシュ値はスクリプトが確認するので、手入力は不要です。 取り込みには時間がかかることがあります。完了まで画面を閉じずに待ちましょう。同じ名前がすでにあるというエラーや、照合の不一致が出た場合は、環境や指定値を書き換えずに画面を残してください。

ブイエスコードで実行できない場合は、接続先と開いているフォルダーから確認します。タスクがなければワーク全体を開いているか、カーネルがなければ授業用接続とジュピター拡張を見ます。 制限モードを解除する場合も、教員配布のワークであることを確認してください。システムディーの警告が出たときも、別のダブリューエスエルでの作業を勝手に止めず、教員に相談します。

補足：Start.cmdを使わない起動方法

WindowsのPowerShell → Ubuntuの画面

① 普通のPowerShellで実行

wsl -d DSProg2026 --cd /home/datasci/work

② Ubuntuの画面に変わってから実行

code .

code と . の間に、半角の空白を入れます。

開いたVS Codeで、WSL: DSProg2026とworkを確認します。

出典：マニュアル「起動用ファイルを使わない予備の方法」

普段はスタート・シーエムディーを使いますが、必要になった場合の予備の起動方法です。最初の一行は、ウィンドウズの普通のパワーシェルで入力します。 ウブントゥの画面に切り替わってから、コード、半角空白、点と入力します。二つのコマンドを同じ操作場所で入力しないように注意してください。開いた後の接続先とフォルダーの確認は、通常の起動と同じです。

補足：JupyterLabは教員の案内時だけ

VS Code｜新しいターミナル（Ubuntu側）

cd /home/datasci/work
uv run --locked jupyter lab
  • 表示されたlocalhostのURLを、token=… まで含めてWindowsのブラウザーで開きます。
  • 「Password or token」は Jupyterの認証です。
  • WindowsやUbuntuのパスワードを入力する画面ではありません。
  • 終了時は起動したターミナルで Ctrl＋C、表示に従います。
トークンを共有せず、認証を無効にしません。通常はVS CodeでNotebookを実行。

出典：マニュアル「ブラウザーのJupyterLabは予備として使える」

ジュピターラボは予備の方法です。教員から案内されたときだけ、授業用ブイエスコードで新しいターミナルを開き、ウブントゥ側でこの二行を実行します。 表示されたローカルホストのアドレスには認証用のトークンが含まれます。アドレス全体を他人へ送らないでください。終了するときは起動したターミナルでコントロールとシーを押し、表示に従います。見えている管理ファイルは変更しません。
