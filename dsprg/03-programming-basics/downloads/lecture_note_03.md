## 3 A 商品の合計金額を計算する

**問い：単価120円の商品を2個買うと、合計はいくらでしょうか。**

まず紙や頭の中で答えを考えてから、コードを実行します。

### Python

`lesson03.py` に書きます。

```python
price = 120
quantity = 2
total = price * quantity
print(f"合計は{total}円です")
```

### R

`lesson03.R` に書きます。

```r
price <- 120
quantity <- 2
total <- price * quantity
cat("合計は", total, "円です\n", sep = "")
```

どちらも、次の内容が表示されます。

```text
合計は240円です
```

### 名前を付けて使う

`price` は単価、`quantity` は個数、`total` は合計金額に付けた名前です。このように値に名前を付けて扱うものを**変数**といいます。

Pythonの `=`、Rの `<-` は、右側の値を左側の名前に結びつける**代入**です。数学の等号とは役割が違います。3行目では右側の掛け算を行い、その結果を `total` に代入しています。掛け算の記号は両言語とも `*` です。

4行目は結果の表示です。Pythonの `print()` とRの `cat()` は、表示するための**関数**です。関数は、名前に続く丸括弧の中へ渡した値を使って処理します。

Pythonでは、`f"..."` の中の `{total}` が変数の値に置き換わります。Rの例では、`cat()` に渡した文字と値を順に表示し、`\n` で改行します。まずは表示の行をそのまま使って大丈夫です。

### 表示の行を読む：文字・引数・戻り値

`120` は計算に使う数値、`"合計は"` は引用符で囲んだ**文字列**です。引用符は文字列の始まりと終わりを示し、表示には出ません。`total` は変数の値240を指しますが、`"total"` はそのつづりを表示する文字列です。

関数へ渡す値や設定を**引数**、処理の結果として呼び出し元へ返る値を**戻り値**と呼びます。画面への表示と戻り値は別です。例えば§5の `mean(...)` は平均値を返し、`print(...)` がその値を表示します。ここでは戻り値を保存するためではなく、画面で結果を見るために表示関数を使います。

| 表示の行の部分 | 意味 |
| --- | --- |
| Pythonの `f"合計は{total}円です"` | 先頭の `f` により、`{total}` を240に置き換えて文字列を作る |
| Pythonの `print(...)` | 丸括弧内の文字列を表示して改行する。戻り値は `None`（値がないことを表す） |
| Rの `cat("合計は", total, "円です\n", sep = "")` | カンマで区切って渡した文字・数値を順につなげて表示する |
| Rの `sep = ""` | 引数 `sep` に空文字列を渡し、値の間へ区切り文字を挿入しない。ここでの `=` は引数名と設定値の対応 |
| Rの `\n` | 改行を表す。`cat()` は自動で末尾に改行を付けないため、文字列の中に指定する |

Rの `cat()` は `NULL` を表示せずに返します。Rの `print()` は、渡された値を表示し、その値を表示せずに返します。戻り値の違いを暗記する必要はありませんが、**計算する行と、表示する行を区別**して読んでください。

### 少し変えてみる

`quantity` を2から3へ変えます。出力を予想してから保存・実行し、予想と比べてください。両言語で確かめたら、個数を2へ戻します。

## 4 B 複数の数値をまとめて計算する

次は、架空の4件の学習時間です。

| 記録 | 学習時間 分 |
| --- | ---: |
| A | 15 |
| B | 30 |
| C | 45 |
| D | 60 |

**問い：この4件を、時間単位で表すとどうなるでしょうか。** 60分が1時間なので、各値を60で割ります。

### Python

Aのコードの下へ追加します。

```python
import numpy as np

study_minutes = np.array([15, 30, 45, 60])
study_hours = study_minutes / 60
print(study_minutes)
print(study_hours)
```

### R

Aのコードの下へ追加します。

```r
study_minutes <- c(15, 30, 45, 60)
study_hours <- study_minutes / 60
print(study_minutes)
print(study_hours)
```

時間単位の値は、両言語とも **0.25、0.5、0.75、1** になります。括弧、空白、小数点以下の表示は違っても、数値の意味は同じです。Aの計算もファイルに残っているので、合計金額も再び表示されます。

### まとめて扱うための数値列

Pythonの `np.array(...)` はNumPyという道具を使い、計算しやすい数値の配列を作ります。`import numpy as np` はその道具を `np` という短い名前で使うための行です。

Rの `c(...)` は値をまとめ、ここでは数値の**ベクトル**を作ります。Pythonの配列とRのベクトルには性質の違いがありますが、今日の例では、複数の値をまとめて計算するために使っています。

| 作る手順 | 渡すもの（引数） | 得られるもの（戻り値） |
| --- | --- | --- |
| Pythonの `np.array([15, 30, 45, 60])` | 角括弧 `[...]` で4個の値をまとめた**リスト** | 要素ごとの計算に使うNumPy配列 |
| Rの `c(15, 30, 45, 60)` | カンマで区切った4個の数値 | 4個の値を持つ数値ベクトル |

どちらも返された数値列を `study_minutes` に代入します。Pythonのリストは値をまとめたもので、そのまま `/ 60` では割れません。この例では `np.array(...)` で配列にしてから計算します。`np.array` のドットは「`np` として読み込んだNumPyの `array` を使う」という意味です。`import` は既に入っている道具をプログラムで使えるようにする行で、インストールの指示ではありません。

`study_minutes / 60` は、一つひとつの値を60で割ります。4行の割り算を別々に書かなくても、まとめて変換できます。

計算結果の数値列は `study_hours` に代入します。元の `study_minutes` は分のまま残るので、二つの `print(...)` で変換前後を比較できます。Rの `print(...)` も、ここでは引数に渡した数値列を表示するために使っています（§3参照）。

Rの出力の先頭にある `[1]` は、この行の先頭が第1要素であることを示す表示です。学習時間として1が追加されたわけではありません。

### 確かめる

60分が1時間になっているか、15分が0.25時間になっているかを見ます。単位を自分で確かめると、単に「エラーが出なかった」以上の確認ができます。

## 5 C 小さい表から一列を取り出す

学習時間に小テスト得点を加え、表にします。**すべて教材用の架空データ**です。

| id | study_minutes | quiz_score |
| --- | ---: | ---: |
| A | 15 | 40 |
| B | 30 | 60 |
| C | 45 | 80 |
| D | 60 | 70 |

横の一行が一つの記録、縦の一列が一種類の情報です。`study_minutes` の単位は分、`quiz_score` の単位は点です。このように行と列を持つ表を、ここでは**データフレーム**として扱います。

### Python

Bのコードの下へ追加します。表を作る部分は、配布例を使って構いません。

```python
import pandas as pd

records = pd.DataFrame({
    "id": ["A", "B", "C", "D"],
    "study_minutes": study_minutes,
    "quiz_score": [40, 60, 80, 70]
})
print(records)
print(records["study_minutes"])
print(records["study_minutes"].mean())
```

### R

Bのコードの下へ追加します。

```r
records <- data.frame(
  id = c("A", "B", "C", "D"),
  study_minutes = study_minutes,
  quiz_score = c(40, 60, 80, 70)
)
print(records)
print(records$study_minutes)
print(mean(records$study_minutes))
```

Pythonのpandas、Rの `data.frame()` を使って、同じ内容の表を作っています。表を作る記号を一度にすべて覚えようとせず、**列の名前と、そこに入る値**を探してください。

`study_minutes` 列には、Bで作った数値列を入れています。コードの中に学習時間の値をもう一度書き直す必要はありません。

### 表を作る記号と引数を読む

Pythonの `import pandas as pd` は、pandasを `pd` という短い名前で読み込む行です（§4の `np` と同じ考え方）。`pd.DataFrame(...)` に渡している `{...}` は、名前と値を対応させた**辞書**です。この例では `"列名": 値` をカンマで区切って並べます。

- `"id": ["A", "B", "C", "D"]`：列名 `id` と、4個の文字列を持つリストの組。
- `"study_minutes": study_minutes`：左は列名の文字列、右はBで作った変数。引用符の有無を見分けます。
- `"quiz_score": [40, 60, 80, 70]`：列名と、4個の数値を持つリストの組。

外側の `(...)` は道具へ引数を渡す括弧、`{...}` は列名と値の対応、`[...]` はこの表を作る箇所では値のリストです。`pd.DataFrame(...)` は、その対応を受け取って**4行3列の表を返し**、`records` に代入します。Aのf文字列の `{total}` は値を埋め込む記号なので、同じ波括弧でも使う場所によって役割が異なります。

Rの `data.frame(...)` は、**引数の名前を列名として使い**、渡された値から表を作ります。`id = c(...)` なら列名は `id`、内容は `c(...)` が返したベクトルです。`study_minutes = study_minutes` の左側は作る列の名前、右側はBで作った変数です。同じつづりでも役割が異なり、この箇所は変数を更新する代入ではありません。戻り値の表を `<-` で `records` に代入します。

どちらの主例も各列に4個の値を用意し、同じ位置の値が同じ行に入ります。例えば最初の行はA・15分・40点です。列の長さや並び順を変えるときは、この対応を確かめます。

### 一列を取り出す

| したいこと | Python | R |
| --- | --- | --- |
| 表全体を表示する | `print(records)` | `print(records)` |
| 学習時間の列を取り出す | `records["study_minutes"]` | `records$study_minutes` |
| その列の平均を計算する | `records["study_minutes"].mean()` | `mean(records$study_minutes)` |

最初は表全体、次は学習時間の4個の値、最後は平均の **37.5分** が出ます。平均は「合計を件数で割った値」です。今回は関数を呼んで計算し、詳しい読み方は次回に学びます。

Pythonの `.mean()` は取り出した列の平均を計算する書き方、Rの `mean(...)` は丸括弧に渡した数値列の平均を計算する書き方です。

Pythonの `records["study_minutes"]` は、表に角括弧で列名を指定して**1列分のデータ（Series）**を取り出します。ここでの角括弧はリストの作成ではなく、表からの選択です。Rの `records$study_minutes` は `$` の右に列名を書いて数値ベクトルを取り出します。

`print(records["study_minutes"].mean())` は、内側から「列を取り出す→その列の `.mean()` で平均を返す→`print(...)` で表示する」の順です。`.mean()` の丸括弧には追加の引数を入れていませんが、ドットの左側にある列が計算対象です。このように対象に結びつけて呼ぶ関数を**メソッド**と呼びます。Rの `print(mean(records$study_minutes))` も、列を取り出し、それを `mean(...)` の引数として渡し、返った数値37.5を表示します。

出力の左側の行ラベルや、列の名前・型を知らせる表示は、言語によって異なります。今日比べるのは、その見た目の完全一致ではなく、4件のデータと計算結果です。
