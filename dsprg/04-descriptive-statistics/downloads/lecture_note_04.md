## 4 数字で要約する

**件数**は記録の数です。**平均**は合計を件数で割った値です。学習時間の合計は660分なので、平均は660÷12＝55分です。

**中央値**は、小さい順に並べたときの中央の値です。12件のように偶数なら、中央の2件を平均します。今回は6番目が45分、7番目が60分なので、(45＋60)÷2＝52.5分です。元の表の6行目・7行目をそのまま選ぶのではありません。

**標準偏差**は、平均のまわりのばらつきを数値で表します。学習時間なら単位は分です。値が大きいほどばらつきが大きいと読みますが、どのデータも平均から同じ距離にあるという意味ではありません。

標準偏差の計算には、偏差の二乗の合計を件数 **n** で割る方法と、**n−1** で割る方法があります。今日は両言語とも **n−1で割ってから平方根を取る標本標準偏差**を使います。12件なら分母は11です。データだけでなく、この定義も揃えて比べます。

### Rで主例を実行する

`lesson04.R` のAを見ます。表は `data.frame(...)` で作り、列を関数へ渡します。

```r
cat("件数:", nrow(records), "\n")
cat("学習時間の平均:", mean(records$study_minutes), "\n")
cat("中央値:", median(records$study_minutes), "\n")
cat("標本標準偏差:", sd(records$study_minutes), "\n")
```

`sd()` はn−1を分母に使います。`cat()` は文字と計算結果を表示し、`\n` で改行します。主例全体を実行すると、表・数値が表示され、後の節で見る図も保存されます。

### Pythonでも主例を実行する

`lesson04.py` のAを見ます。表はpandasの `pd.DataFrame(...)` で作ります。

```python
print("件数:", len(records))
print("学習時間の平均:", records["study_minutes"].mean())
print("中央値:", records["study_minutes"].median())
print("標本標準偏差:", records["study_minutes"].std(ddof=1))
```

`ddof=1` は分母をn−1にする指定です。表示桁数が違っても、両言語で12件、平均55分、中央値52.5分、標本標準偏差約27.386分になれば照合できています。

### 何を渡して、何が返るか

| 処理 | R | Python | 今回の戻り値 |
| --- | --- | --- | --- |
| 表の行数を数える | `nrow(records)` | `len(records)` | 数値12 |
| 学習時間の平均 | `mean(records$study_minutes)` | `records["study_minutes"].mean()` | 数値55 |
| 中央値 | `median(records$study_minutes)` | `records["study_minutes"].median()` | 数値52.5 |
| 標本標準偏差 | `sd(records$study_minutes)` | `records["study_minutes"].std(ddof=1)` | 数値約27.386 |

Rは取り出した列を関数の引数へ渡します。Pythonの列に続く `.mean()` などは、その列に対する処理です。`std(ddof=1)` は、引数 `ddof` に1を渡して分母を指定しています。`mean()` のように丸括弧が空でも、ドットの左の列が計算対象です。

表を作る行のRの `LETTERS[1:12]` は、大文字の並び `LETTERS` から1〜12番目を取り出したA〜Lです。`1:12` は連続した番号を作ります。Pythonの `list("ABCDEFGHIJKL")` は、一つの文字列を1文字ずつのリストへ変換して返します。どちらも12行に対応する記録名です。

## 5 二つの図を読み分ける

主例B・Cは、**データを選ぶ → 図を作る → 軸・ラベルを設定する → 保存して開く**という順で読みます。図を作る処理と、画像ファイルを保存する処理は別です。配布コードには両方が入っています。以下の短いコードは読む箇所を示しており、主例全体を置き換えるものではありません。

### ヒストグラム：どの時間帯に何件あるか

主例Bは、学習時間を幅30分の区間へ分け、件数を棒の高さにします。横軸は学習時間、縦軸は件数です。

| 区間 | 主例の件数 |
| --- | ---: |
| 0分以上30分未満 | 1 |
| 30分以上60分未満 | 5 |
| 60分以上90分未満 | 5 |
| 90分以上120分未満 | 0 |
| 120分以上150分以下 | 1 |

30分は2番目、60分は3番目の区間です。両言語とも左端を含み、右端を含みません。ただし最後の区間は150分も含めます。件数の合計が12になることを確認します。

```r
geom_histogram(breaks = breaks, closed = "left", colour = "white")
```

```python
ax.hist(records["study_minutes"], bins=breaks, edgecolor="white")
```

`breaks` は両方とも0,30,60,90,120,150です。境界を変えると棒のまとまり方も変わります。今回は比較のために固定します。

### R：データと描き方を組み合わせる

`ggplot(records, aes(x = study_minutes))` の第1引数は表です。`aes(...)` は、表のどの列をどの位置に対応させるかを指定します。ここでは `x` に学習時間の列を指定します。**`aes()` 内の列名は引用符で囲みません。** `x = study_minutes` は横軸への対応指定であり、変数 `x` を更新する代入ではありません。

`ggplot(...)` が返す図の土台に、`+` で描画や設定の要素を加えます。ここでの `+` は数値の足し算ではなく、図の構成要素を組み合わせる記号です。`geom_histogram(...)` はヒストグラムの描き方を返し、`breaks` に境界の数値列、`closed` に左端を含む指定を渡します。`colour = "white"` は棒の枠線を白にする設定です。

全体の結果を `histogram <- ...` で保存します。この `histogram` は件数の配列やPNGではなく、後で描画・保存できる**図の情報**です。`scale_x_continuous(...)`・`scale_y_continuous(...)` は目盛りと軸範囲、`labs(...)` は軸名とタイトル、`theme_minimal(...)` は見た目や文字を設定する要素です。引数の読み方は末尾の補足で確認できます。

### Python：図全体と描く場所を受け取る

`fig, ax = plt.subplots(figsize=(8, 5))` は図全体と一つの描画領域を作ります。**二つの戻り値を、順に `fig` と `ax` で受け取る**書き方です。`fig` は図全体、`ax` は軸・棒・点などを配置する場所です。`figsize=(8, 5)` は幅8・高さ5インチの指定です。

`ax.hist(...)` の第1引数は学習時間の列、`bins=breaks` は区間境界、`edgecolor="white"` は棒の枠線です。この処理は `ax` に棒を描き、件数・境界・描かれた棒の情報を返します。主例では戻り値を変数へ保存せず、図と元データで件数を確かめます。

`ax.set(...)` は同じ描画領域へ軸名・タイトル・表示範囲・目盛りを設定します。戻り値は設定結果の一覧ですが、ここでは保存していません。図が描かれたという変化と、戻り値の保存を区別して読んでください。

### 散布図：二つの値を一組で見る

主例Cでは、1件の学習時間と得点を一つの点にします。横軸は学習時間（分）、縦軸は小テスト得点（点）です。Lは(120,90)にあります。

```r
scatter <- ggplot(records, aes(x = study_minutes, y = quiz_score)) +
  geom_point(size = 3)
```

```python
ax.scatter(records["study_minutes"], records["quiz_score"])
```

DとJはどちらも(60,70)なので点が重なります。見える点の数だけで記録が足りないとは判断できません。元の表の件数と照合します。この架空の12件だけから、学習時間を延ばせば必ず得点が上がる、とは言えません。

Rの `aes(x = study_minutes, y = quiz_score)` は、同じ行の二列を横軸・縦軸へ対応させます。`geom_point(size = 3)` は点を描く要素を返し、`size` は点の大きさです。完成した図の情報を `scatter` に代入します。

Pythonの `ax.scatter(...)` も、第1引数に横軸の列、第2引数に縦軸の列を渡します。点の集まりを描画領域へ追加し、その描画情報を返します。この戻り値も主例では保存しません。Cの冒頭で再び `plt.subplots(...)` を呼ぶので、ヒストグラムとは別の図になります。

### 保存場所を作り、図をファイルにする

タスクの作業場所は `work` です。`exercises/lesson04/output` という**相対パス**は、その場所からたどる保存先です。

| 目的 | R | Python |
| --- | --- | --- |
| 保存先を指定 | `output <- "exercises/lesson04/output"`：パスを表す文字列 | `output = Path("exercises/lesson04/output")`：パスを扱う値を作る |
| フォルダーを用意 | `dir.create(output, recursive = TRUE, showWarnings = FALSE)` | `output.mkdir(parents=True, exist_ok=True)` |
| 保存先とファイル名を結合 | `file.path(output, "lesson04_r_hist.png")` | `output / "lesson04_python_hist.png"` |

Rの `recursive = TRUE`、Pythonの `parents=True` は途中のフォルダーも作る指定です。Rの `showWarnings = FALSE` は既存フォルダー等の警告表示を抑え、Pythonの `exist_ok=True` は既存フォルダーがあってもエラーにしない指定です。Rの `dir.create()` は作成の成否を表示せず返し、Pythonの `mkdir()` は `None` を返します。主例では戻り値を保存せず、その後の画像保存とファイルの存在で確認します。Rで権限などの理由により作れなければ、警告を抑えても保存が成功するわけではありません。

Pythonのパスに使う `/` はフォルダーとファイル名をつなぐ操作です。数値の割り算とは使う対象が違います。Rの `file.path(...)` は、結合したパスの文字列を返します。

Rの `ggsave(file.path(...), plot = histogram, width = 8, height = 5, dpi = 150)` は、第1引数の保存先へ、`plot` で指定した図を保存します。散布図では `plot = scatter` を渡します。戻り値は保存先の文字列で、画面には自動表示しません。画像は幅8・高さ5インチ、1インチあたり150画素なので1200×750画素です。

Pythonでは `fig.tight_layout()` が余白を調整し、`fig.savefig(..., dpi=150)` が指定先へ図全体を保存します。保存後の `plt.close(fig)` は使い終えた図を閉じる処理で、保存済みPNGを削除しません。これらの戻り値は `None` で、主例では保存していません。

最後のRの `normalizePath(output)`、Pythonの `output.resolve()` は、保存場所を絶対パスにして返します。その結果を `cat()`・`print()` に渡して表示しているので、どこへ保存されたか確認できます。

| 横軸の目盛り | `scale_x_continuous(breaks = breaks, ...)` | `ax.set(xticks=breaks, ...)` | 0、30、60、90、120、150の位置に目盛りを置く |
| 縦軸の目盛り | `scale_y_continuous(breaks = 0:6, ...)` | `ax.set(yticks=range(7), ...)` | 0〜6の件数を表示。Pythonの `range(7)` は7を含まない |
| 名前とタイトル | `labs(x = ..., y = ..., title = ...)` | `ax.set(xlabel=..., ylabel=..., title=...)` | データ列を入れ替えず、表示する文字列を設定する |
| ヒストグラムの範囲 | `scale_*_continuous(limits = c(...))` | `ax.set(xlim=(...), ylim=(...))` | 横0〜150、縦0〜6で両言語を比べる |
| 散布図の範囲 | `coord_cartesian(xlim = c(0, 150), ylim = c(0, 100))` | `ax.set(xlim=(0, 150), ylim=(0, 100))` | 学習時間と得点の範囲をそろえる |

Rの `scale_*_continuous(limits=...)` は範囲外の値を除外する場合があり、`coord_cartesian(...)` は表示範囲を設定します。両者を無条件に同じ処理とは考えません。今回のデータは指定範囲内です。目盛りの `breaks` と、ヒストグラムで件数を数える区間の `breaks` も、渡す関数によって役割が違います。主例では同じ数値列を使って見やすくしています。

Pythonの `rcParams` は以後作る図の既定設定を保存するもの、Rの `theme_minimal(...)` は `+` で加えるテーマを返すものです。どちらも元の学習時間や得点を変えません。図の表示が変わった場合も、数値・軸・単位を別々に確認してください。

### 標準偏差と今回扱わないこと

標本標準偏差は $s=\sqrt{\sum_{i=1}^{n}(x_i-\bar{x})^2/(n-1)}$ です。分母nの標準偏差とは値が違います。「不偏標準偏差」と単純に呼ぶことは避けます。

Pythonのpandasの `std()` は既定でもddof=1ですが、比較の意図を示すため明記しました。NumPyの `std()` は既定がddof=0です。道具が違うと既定値も違うので確認します。

今回の表には欠損値がありません。欠損がある場合の件数や除外の扱いは第6回で扱います。相関係数、回帰、群別集計、箱ひげ図の追加は今回の必須課題ではありません。
