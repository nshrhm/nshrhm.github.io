## 3 仮想母集団とseed

母集団は、推測の対象となる全体です。標本は、その全体から得た一部の値です。今回はコンピューターの中に、平均50・標準偏差10の正規分布という仮想モデルを置き、独立な乱数を12個作ります。正規分布は、中心の近くが多く、離れた値が少ない釣鐘型の分布です。12個だけでは、きれいな釣鐘型に見えるとは限りません。

これは実際の学生の学習時間や成績を表しません。値の単位も授業用の任意単位です。

| 設定 | 意味 | 主例の値 |
| --- | --- | ---: |
| mu | 仮想母平均 | 50 |
| sigma | 仮想母標準偏差 | 10 |
| n | 1回の標本サイズ | 12 |
| seed | 乱数の開始状態を決める番号 | 2026 |

seedは、乱数の開始状態を決めるための番号です。同じ環境・同じコード・同じseedで最初から実行すると、同じ乱数列を再現できます。乱数生成だけを続けて呼ぶと、その続きの値になります。

Rは `set.seed(seed)`、Pythonは `np.random.default_rng(seed)` で開始状態を設定します。**同じseed番号でも、PythonとRの乱数列が一致するとは限りません。** 比べるのは統計的な考え方と計算の定義です。

## 4 Rで主例を実行する（15〜30分）

`lesson05.R` の完成例を使います。まず「平均はちょうど50になるか」を予想してください。

```r
# 仮想母集団。実在の学生の記録ではありません。
seed <- 2026
n <- 12
mu <- 50
sigma <- 10
set.seed(seed)
sample <- rnorm(n, mean = mu, sd = sigma)
average <- mean(sample)
s <- sd(sample)  # 分母 n−1
critical <- qt(0.975, df = n - 1)
margin <- critical * s / sqrt(n)
lower <- average - margin
upper <- average + margin
cat("標本:", sample, "\n")
cat("平均:", average, "\n")
cat("標本標準偏差:", s, "\n")
cat("95%信頼区間の下限:", lower, "\n")
cat("95%信頼区間の上限:", upper, "\n")
```

最初は `set.seed()`、`rnorm()`、`mean()`、`sd()` の行を探します。12個の値と平均が表示されれば最初の到達点です。第4回と同じく `sd()` は分母n−1の標本標準偏差です。母集団に指定した10と、標本から計算した標準偏差が一致する必要はありません。

同じファイルをもう一度、最初から実行します。標本と平均は変わりましたか。結果を残して比較してください。seedを変える操作は、後の演習ファイルで行います。

### 区間の読み方

平均を一点で答えるだけでは、標本による変動が見えません。そこで、平均を中心に幅を持たせた区間を作ります。

**標本平均 ± tの臨界値 × 標本標準偏差 / √n**

この授業では、独立な正規乱数の標本から母平均を推定するt信頼区間を使います。`critical` はtの臨界値、`margin` は平均から端までの幅、`lower` と `upper` は下限と上限です。`qt(0.975, df = n - 1)` は両側95%に対応し、今回は自由度11です。ここは配布済みの計算を使って構いません。

「95%」は、**標本を繰り返し取り、同じ方法で区間を作ると、おおむね95%の区間が真の母平均を含む**という意味です。得られた一つの区間に母平均が95%の確率で存在する、という意味ではありません。

今回は検証のために母平均50を知っています。実際の推測では母平均は未知です。一回の区間が50を含まなくても、それだけで計算間違いとはいえません。

## 5 Pythonで同じ考え方を確かめる（30〜45分）

`lesson05.py` の完成例を使います。乱数値をRと一致させる必要はありません。

```python
# 仮想母集団。実在の学生の記録ではありません。
import numpy as np

seed = 2026
n = 12
mu = 50
sigma = 10
rng = np.random.default_rng(seed)
sample = rng.normal(mu, sigma, n)
average = np.mean(sample)
s = np.std(sample, ddof=1)  # 分母 n−1
from scipy.stats import t
critical = t.ppf(0.975, df=n - 1)
margin = critical * s / np.sqrt(n)
lower = average - margin
upper = average + margin
print("標本:", sample)
print("平均:", average)
print("標本標準偏差:", s)
print("95%信頼区間の下限:", lower)
print("95%信頼区間の上限:", upper)
```

### 道具を読み込み、標本を作る

`import numpy as np` は数値計算の道具NumPyを読み込み、以後は `np` という短い名前で使う宣言です。`=` は右側の結果に左側の変数名を付ける代入です。`seed` は乱数の開始状態、`n` は個数、`mu` は母平均、`sigma` は母標準偏差です。

```python
rng = np.random.default_rng(seed)
sample = rng.normal(mu, sigma, n)
```

1行目の `np.random` はNumPyの乱数の機能です。`default_rng(seed)` は、丸括弧内の値（引数）を使って**乱数生成器**を作り、それを返します。呼び出しの結果を戻り値と呼びます。この戻り値を `rng` に代入します。`rng` は乱数を作るための状態を持つ道具で、この時点では12個の標本ではありません。

2行目の `rng.normal(...)` は、その生成器が持つ正規乱数を作る機能を呼び出します。ドットは左側の道具の機能を指定する書き方です。引数の順番は、**母平均・母標準偏差・個数**。ここでは平均50、標準偏差10の正規分布から12個を取り出し、数値をひとまとめにしたNumPyの配列を `sample` に代入します。2番目は分散ではなく標準偏差です。確認用に `print(len(sample))` を実行すると12と表示されますが、標本平均が必ず50になるわけではありません。

同じ環境・同じseedで生成器を作り直し、同じ順で使えば再現できます。一方、生成器を作り直さずに `rng.normal(...)` だけを続けて実行すると、状態が進んで次の標本が得られます。そのため、再現の確認ではファイル全体を最初から実行します。

### 標本から平均とばらつきを計算する

`np.mean(sample)` は値を足して個数で割り、結果を `average` に代入します。`np.std(sample, ddof=1)` は分母n−1の標本標準偏差を計算し、結果を `s` に代入します。`ddof=1` は名前付きの引数です。NumPyでは指定を省くと分母nになるので、今回は残します。母集団の設定 `mu`・`sigma` と、今回の標本から計算した `average`・`s` を区別してください。

### SciPyで区間計算の係数を求める

`from scipy.stats import t` は、SciPyの統計機能からt分布を扱う `t` を読み込みます。続く `t.ppf(0.975, df=n - 1)` は、t分布の左側の面積が0.975となる境界の値を返します。中央95%の外側には左右2.5%ずつが残るため、右の境界までの面積は97.5%です。`df` は自由度を指定する名前付きの引数で、今回は12−1＝11です。戻り値を `critical` に代入すると約2.201になります。Rの `qt()` と同じ役割で、区間幅を求めるための係数です。

### 区間を計算し、表示する

求めた係数 `critical` を使って区間の両端を計算します。`np.sqrt(n)` は√n、`*` は掛け算、`/` は割り算です。`margin` は平均から片方の端までの幅で、区間全体の幅ではありません。`average - margin` が下限 `lower`、`average + margin` が上限 `upper` です。全体の幅は `upper - lower` で、`margin` の2倍になります。

`print("平均:", average)` は、引用符で囲んだ見出しの文字と、変数に入った値を表示します。他の `print` も同じ仕組みで、標本、標本標準偏差、区間の下限・上限を表示しています。

**確認：Pythonでも、同じファイルを最初から再実行して標本と平均が再現しましたか。** 下限≤平均≤上限も確かめます。同じseedを再実行することと、新しい標本を取ることは区別しましょう。

## 補足：授業後に参照すること

このモデルでは標本平均の標準偏差はσ/√nです。標本サイズを増やすと平均のばらつきは一般に小さくなりますが、個々の試行で誤差や区間幅が必ず単調に小さくなるわけではありません。

計算する区間は母平均のための区間で、個々の値の95%が入る区間ではありません。独立性や母集団の分布が前提と合わない実データへ、そのまま当てはめてよいとは限りません。追加の分布、仮説検定・p値・ベイズ推定は今回の必修に含めません。
