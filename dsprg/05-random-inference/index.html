平均の推測に、幅を持たせる。

下限 ───── 標本平均 ───── 上限

ここから95パーセント信頼区間を導入します。この幅は個々の値のばらつきそのものではなく、母平均を推測するための幅です。

配布の式で、区間を計算する

標本平均 ± tの臨界値 × 標本標準偏差 / √n

  • 独立な正規乱数の標本を前提にする。
  • 今回はn=12、自由度n−1=11。
  • 証明や手計算の暗記は不要。
母標準偏差の設定は10ですが、今回は未知として標本標準偏差から推定する方法を学びます。区間がどこから来るかを配布式で確認します。

R：平均から両端へ

critical <- qt(0.975, df = n - 1)
margin <- critical * s / sqrt(n)
lower <- average - margin
upper <- average + margin
両側95パーセントでは両端に2.5パーセントずつ残すので0.975を使います。marginは区間全体の幅ではなく、中心から端までの距離です。

lesson05.pyをダウンロード。詳しい説明は講義ノートの第5節へ。

ここからPythonです。配布されたレッスン05のパイファイルを開き、画面の行を探してください。インポート、ナンパイ、アズ、エヌピーは、数値計算の道具であるNumPyを読み込み、以後はエヌピーという短い名前で使うという意味です。イコールは左右が等しいかを調べる記号ではなく、右側の値に左側の変数名を付ける代入です。シードは乱数の開始状態を決める2026、エヌは取り出す個数の12です。ミューは母平均50、シグマは母標準偏差10です。この50と10は仮想母集団の設定であり、これから得る12個の平均と標準偏差が必ずこの値になる、という指定ではありません。

Python：乱数生成器を用意する

rng = np.random.default_rng(seed)
  • np.random：NumPyの乱数の機能。
  • default_rng(seed)：seedを渡し、乱数生成器を作る。
  • 戻り値（呼び出しの結果）を、rngという名前で使う。

この行は準備。まだ12個の標本は作っていない。

同じ環境・同じseedで作り直し、同じ順に使うと再現。

この行は、右側から読みます。エヌピー、ドット、ランダムは、NumPyの乱数の機能を指します。デフォルト、アールエヌジーは乱数生成器を作る関数です。丸括弧の中のシードが、関数へ渡す値、つまり引数です。ここでは先ほど代入した2026を渡します。関数が返す乱数生成器を、左側のアールエヌジーという変数名で使えるようにします。乱数生成器は、次の乱数を作るための状態を持った道具です。この行では、12個の標本を作る準備までをしています。同じ環境で同じシードから生成器を作り直し、同じ順番で乱数を取り出せば、結果を再現できます。一方、作り直さずに続けて取り出すと、生成器の状態が進むので次の乱数が得られます。

Python：正規分布から12個を取り出す

sample = rng.normal(mu, sigma, n)

rng.normal(...)：用意した生成器の正規乱数を作る機能。

渡す順序 今回の値 意味
1番目：mu 50 母平均（分布の中心）
2番目：sigma 10 母標準偏差（分布の広がり）
3番目：n 12 取り出す個数

結果は12個の数値の配列。sampleに代入する。

確認：len(sample)は12。標本平均は50とは限らない。

次の行で、実際に標本を作ります。アールエヌジー、ドット、ノーマルは、先ほど用意した生成器の、正規分布に従う乱数を作る機能を呼び出しています。ドットは、左側の道具が持つ機能を使う書き方です。丸括弧の中には、順番に、母平均のミュー、母標準偏差のシグマ、個数のエヌを渡します。この例では、平均50、標準偏差10の正規分布から12個を取り出します。2番目は分散ではなく標準偏差なので、100に置き換えないでください。戻り値は、複数の数値をひとまとめにしたNumPyの配列です。それをサンプルという変数に代入します。レングスを表すレン関数でサンプルの個数を調べると12になります。ただし、12個の平均が50、標準偏差が10になる保証はありません。全ファイルを最初から再実行する場合は生成器も作り直されますが、このノーマルの行だけを続けて実行する場合は次の標本が得られる、という違いにも注意しましょう。

Python：平均と標本標準偏差

average = np.mean(sample)
s = np.std(sample, ddof=1)
  • np.mean(sample)：標本の値を足し、個数で割る。
  • 結果をaverage（標本平均）に代入する。
  • np.std(...)：標本のばらつきを計算し、sに代入。
  • ddof=1：名前付きの引数。分母をn−1にする。

母集団の設定mu・sigmaと、標本のaverage・sを区別。

標本ができたら、その12個から平均と標本標準偏差を計算します。エヌピー、ドット、ミーンにサンプルを渡すと、値を足して個数で割った平均が返ります。それをアベレージに代入します。次のエスティーディーは標準偏差を計算する機能です。ディーディーオーエフ、イコール1は、丸括弧の中で引数の名前を指定する書き方で、分母をエヌから1引いた値にします。NumPyでは省略すると分母がエヌになるので、今回は必ず残します。ここで計算したエスは標本標準偏差です。ミューとシグマが母集団の設定だったのに対し、アベレージとエスは今回得た標本から計算した値です。標本を変えると、この二つも変わります。

Python：臨界値を求める

from scipy.stats import t
critical = t.ppf(0.975, df=n - 1)
  • from ... import t：SciPyの統計機能からtを読み込む。
  • t.ppf(...)：t分布で、左側の面積が指定値になる境界。
  • 中央95% → 両端に2.5%ずつ → 右の境界は0.975。
  • df=n - 1：自由度を指定。今回は12−1＝11。

戻り値をcriticalへ。今回は約2.201（Rのqt()と同じ役割）。

区間の幅を計算するための係数を、SciPyで求めます。フロム、サイパイ、ドット、スタッツ、インポート、ティーは、SciPyの統計機能から、ティー分布を扱う道具を読み込むという意味です。次のティー、ドット、ピーピーエフは、左側の面積を指定すると、その境界の値を返します。中央の95パーセントを使いたいので、残る5パーセントを左右に2.5パーセントずつ分けます。右の境界までの面積は97.5パーセント、つまり0.975です。そのため、ここは0.95ではありません。ディーエフは自由度を指定する名前付きの引数です。今回は標本が12個なので、エヌ引く1で11になります。返された値をクリティカルに代入すると、約2.201です。これは区間の幅を計算するための係数で、標本平均そのものでも、区間幅そのものでもありません。Rのキューティーと同じ役割です。

Python：区間の両端を計算する

margin = critical * s / np.sqrt(n)
lower = average - margin
upper = average + margin
  • 求めたcriticalを使って、上から順に計算する。
  • np.sqrt(n)は√n。*は掛け算、/は割り算。
  • marginは平均から片端までの幅。全体の幅はその2倍。
  • lowerは下限、upperは上限。

末尾のprint("平均:", average)は、見出しと値を表示する。

次に、求めたクリティカルを使って区間の両端を計算します。エヌピー、ドット、スクエアルートはエヌの平方根です。クリティカルに標本標準偏差のエスを掛け、エヌの平方根で割った値を、マージンに代入します。マージンは標本平均から片方の端までの幅です。平均からこれを引くと下限のローワー、足すと上限のアッパーになります。区間全体の幅は、アッパー引くローワーで、マージンの2倍です。ファイル末尾のプリントは表示の命令です。例えば、引用符で囲んだ平均という文字と、アベレージに入った数値を、カンマで区切って渡しています。他のプリントも同じ書き方で、標本、標本標準偏差、下限、上限を表示します。実行したら、下限、平均、上限がこの順に並ぶことを確認してください。

補足：標本サイズを増やしたら？

このモデルでは、標本平均の標準偏差は σ/√n。

nが大きいほど、平均のばらつきは一般に小さい。

個別の試行の誤差や区間幅が、 必ず単調に小さくなるわけではない。

必須演習ではエヌを12に固定します。エヌの変更を追加課題にはしません。教員が標本サイズを変えて実演する場合も、RのキューティーとPythonのティー、ドット、ピーピーエフが、エヌ引く1の自由度に応じた臨界値を計算します。

補足：今回の区間の限界

  • 独立な正規標本を前提にした母平均の区間。
  • 個々の値の95%が入る区間ではない。
  • 実データの偏りや依存関係は別途確認が必要。

出典：学生ノート、教員メモ、実行検証記録。

仮想母平均を知っているのは検証のためです。現実の推測では母平均は未知で、サンプリングの偏りなどはこの式だけでは解決しません。仮説検定やベイズ推定は今回は導入しません。
