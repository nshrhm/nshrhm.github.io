平均を、一点だけで答えない

標本が変われば、平均も変わる。

平均の推測に、幅を持たせる。

下限 ───── 標本平均 ───── 上限

ここから95パーセント信頼区間を導入します。この幅は個々の値のばらつきそのものではなく、母平均を推測するための幅です。

配布の式で、区間を計算する

標本平均 ± tの臨界値 × 標本標準偏差 / √n

  • 独立な正規乱数の標本を前提にする。
  • 今回はn=12、自由度n−1=11。
  • 証明や手計算の暗記は不要。
母標準偏差の設定は10ですが、今回は未知として標本標準偏差から推定する方法を学びます。区間がどこから来るかを配布式で確認します。

R：平均から両端へ

critical <- qt(0.975, df = n - 1)
margin <- critical * s / sqrt(n)
lower <- average - margin
upper <- average + margin
両側95パーセントでは両端に2.5パーセントずつ残すので0.975を使います。marginは区間全体の幅ではなく、中心から端までの距離です。

Rの主例は、50を含まない

seed=2026、n=12

95%信頼区間：約39.241〜49.190

この一回だけで、計算間違いといえる？

実環境で確認した主例は50を含みません。意図的に結果を変えず、この例を使います。まず計算条件を確認し、正しい方法でも含まない区間が出ることを説明します。

95%は、方法を繰り返したときの割合

標本を繰り返し取り、同じ方法で区間を作る。

おおむね95%の区間が、真の母平均を含む。

一つの区間に母平均が95%の確率で存在する、 という意味ではない。

母平均は固定された値です。標本を取り直すと区間が変わります。今手元にある区間は母平均を含むか含まないかのいずれかです。

Python：標本を作る

30–45分 

import numpy as np
seed = 2026
n = 12
mu = 50
sigma = 10
rng = np.random.default_rng(seed)
sample = rng.normal(mu, sigma, n)
30分でPythonへ切り替えます。配布ファイルを開くので入力時間を増やしません。Rとの共通点と、開始状態の作り方の違いを確認します。

Python：平均と標本標準偏差

average = np.mean(sample)
s = np.std(sample, ddof=1)

ddof=1を残す。分母はn−1。

NumPyの既定値は分母nなので、明示してそろえます。第4回に使った道具と異なる場合も、関数の既定値を確認する習慣をつけます。

Python：配布の区間計算を使う

from scipy.stats import t
critical = t.ppf(0.975, df=n - 1)
margin = critical * s / np.sqrt(n)
lower = average - margin
upper = average + margin
学生環境にはSciPyがあります。配布コードにはSciPyのない採点環境向けの処理も付いていますが、学生が編集する必要はありません。固定値はnが12のときに限られます。

補足：標本サイズを増やしたら？

このモデルでは、標本平均の標準偏差は σ/√n。

nが大きいほど、平均のばらつきは一般に小さい。

個別の試行の誤差や区間幅が、 必ず単調に小さくなるわけではない。

必須演習ではnを12に固定します。nの変更を追加課題にはしません。もし教員が実演する場合は、固定臨界値を他のnへ使わず、その自由度で計算してください。

補足：今回の区間の限界

  • 独立な正規標本を前提にした母平均の区間。
  • 個々の値の95%が入る区間ではない。
  • 実データの偏りや依存関係は別途確認が必要。
