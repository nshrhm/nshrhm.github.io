ゼロは記録された値です。空欄は分からないという印です。空欄をゼロに置き換えると、分からない記録がゼロ分の記録へ変わってしまいます。

Python：30分以上を選ぶ

minimum_minutes = 30
selected = complete.loc[
    complete["study_minutes"] >= minimum_minutes,

>= は境界の30分を含む。

しきい値は三十分です。条件の記号は以上なので、三十分ちょうども含みます。行の条件と必要な列を指定して、作業用の表をコピーします。

selected["study_hours"] = (

30〜45分：R主例

次はアールです。ファイル名とタスクがアール用になっていることを確認します。画面の見た目ではなく、残った記録と数値を比べましょう。

R：読む・確認する

records <- read_csv(source_file,
  col_types = column_types, na = "",
  show_col_types = FALSE, progress = FALSE)
print(dim(records))
print(names(records))

col_types は型、na は欠損の指定。

アールでも列の型と空欄の扱いを指定しています。ディムで行列数、ネームズで列名を確認します。読み取る条件を言語間で揃えています。

R：型と欠損を数える

print(sapply(records, class))
print(colSums(is.na(records)))
  • is.na：欠損かどうか
  • colSums：列ごとに数える
  • 0 と NA を区別する
アールではエヌエーが欠損です。イズエヌエーで各値が欠損かを調べ、その結果を列ごとに合計します。ゼロという数値は欠損として数えません。

R：左の結果を右へ渡す

complete <- records |>
  filter(!is.na(study_minutes),
         !is.na(quiz_score))
  • |>：表を次の処理へ渡す。
  • !：「ではない」。
  • 必要な2列が欠損ではない行を残す。
パイプは左の結果を右の処理へ渡す記号です。この例ではレコーズをフィルターへ渡します。エクスクラメーションは否定なので、欠損ではない行を残します。

R：行・列・換算を順に

minimum_minutes <- 30
selected <- complete |>
  filter(study_minutes >= minimum_minutes) |>
  select(id, study_minutes, quiz_score) |>
  mutate(study_hours = study_minutes / 60)
上から順に読みます。条件に合う行を選び、必要な列を選び、時間の列を作ります。一度に長い式を覚えるより、それぞれの段階で何が変わるかを確かめてください。

R：保存して読み直す

write_csv(selected, output_file)
# 再読込の型指定は配布コードを使う
print(names(reloaded))
print(nrow(reloaded))

8行4列、保存前との比較は TRUE。

ライトシーエスブイで保存します。この関数は行番号を書き足しません。配布コードで読み直した表の列と件数を確認し、保存前との比較も読みます。
