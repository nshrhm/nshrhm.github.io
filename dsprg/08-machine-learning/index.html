今日は消費電力量という数値を予測する。

10〜25分：概念と小例

回帰と分類は、正解に相当する目的変数を使って規則を決めます。教師なし学習はまとまりや特徴を探します。今日は回帰の入口として、数値を予測する最小限の規則を作ります。

どの列が、何のためにある？

列 意味・単位
operating_hours 稼働時間［時間］
throughput_units 処理量［個］
energy_kwh 目的変数［kWh］
id / split 照合用ID／分割ラベル

稼働時間・処理量は、次回以降の説明変数候補。

目的変数は予測したい消費電力量です。稼働時間と処理量は予測に使える入力候補ですが、今日はまだ使いません。IDと分割ラベルは分析を管理する列で、予測の説明変数にはしません。

平均だけで予測してもよい？

  • 訓練行から、消費電力量の平均を一つ求める。
  • どの行にも同じ値を予測する。
  • 後のモデルと比べる基準になる。

今回は説明変数を使わない基準モデル。

全て同じ予測では役に立たないように思えるかもしれません。それでも、もっと複雑な方法がどれだけ改善したかを比べる出発点になります。平均をデータから決めることが、今回の学習です。

何で学び、何で確かめる？

学生ノート§3：分割は両言語で共通。

訓練60行で平均を計算し、それを固定して検証20行へ進みます。最終確認20行は今回は配布していません。後の候補比較にも使う検証行を、完全に未使用のテストと呼ばないようにしましょう。図はクリックで拡大できます。

小例：予測値と絶対誤差

訓練値が10と14なら、平均は12です。検証値が9と16でも、予測値は12のままです。図の線と点の距離が絶対誤差で、この例では3と4になります。これは考え方の小例で、配布データの答えではありません。

MAE：絶対値を取ってから平均

符号付きの誤差をそのまま足すと、過大予測と過小予測が打ち消し合います。今回は一つずつ絶対値にしてから平均します。エムエーイーは平均絶対誤差で、単位は元の消費電力量と同じキロワット時です。

予想：検証MAEはどうなる？

  • 訓練MAEより大きい？ 小さい？
  • そう思う理由を一文メモする。
  • 実行後に、実測値と比べる。

大小関係が必ず決まるわけではない。

まだ実行結果を見ていない人は、先に予想を一文書いてください。すでに見た人は、どの行の違いが影響したかを考えましょう。検証の方が必ず大きいという一般則はありません。

Python：行を分け、平均を決める

train = records[records["split"] == "train"].copy()
validation = records[records["split"] == "validation"].copy()
baseline = train["energy_kwh"].mean()
  • 条件が真の行だけを抽出する。
  • .mean() の入力は訓練行の列。
  • 戻り値は一つの予測値。
分割列がトレインと一致する行だけを取り出します。バリデーションも同じように抽出します。重要なのは平均の前にトレインを選んでいることです。コピーや括弧の読み方は学生ノート第4節で確認できます。

R：同じ行から平均を決める

train <- filter(records, split == "train")
validation <- filter(records, split == "validation")
baseline <- mean(train$energy_kwh)
  • filter(表, 条件) が対象行を返す。
  • $energy_kwh が数値列を取り出す。
  • mean の結果は一つの予測値。
Rでも処理の順番は同じです。フィルターは表と条件を受け取り、条件に合う行を返します。ドル記号で目的変数の列を取り出し、ミーンに渡します。Pythonと同じ60行になっているか、IDも見てください。

Python：ずれを一行ずつ求める

train_error = (train["energy_kwh"] - baseline).abs()
train_mae = train_error.mean()
print("訓練MAE kWh", train_mae)

.abs() は各要素の絶対値。 .mean() は絶対誤差の平均。

列から一つの数を引くと、各行について同じ予測値との差を計算します。括弧で引き算をまとめてから絶対値を取ります。その60個の絶対誤差の平均が訓練エムエーイーです。

R：同じ順で絶対誤差を平均する

train_error <- abs(train$energy_kwh - baseline)
train_mae <- mean(train_error)
cat("訓練MAE kWh", train_mae, "\n")

abs(数値ベクトル) → 同じ長さの絶対値。 mean(絶対誤差) → 一つの数値。

Rのエービーエスは数値ベクトルを受け取り、各値の絶対値を返します。行数を減らす操作ではありません。その結果をミーンへ渡し、キャットで単位とともに表示します。

変えるのは評価する行

validation_error = (validation["energy_kwh"] - baseline).abs()
validation_mae = validation_error.mean()
validation_error <- abs(validation$energy_kwh - baseline)
validation_mae <- mean(validation_error)

baselineを計算し直さない。

トレインをバリデーションに変えて、評価する行だけを変更します。平均を求め直す行は追加しません。検証の答えから平均を作り直してしまうと、確認したい未知の値を予測規則に混ぜたことになります。

結果を読む順番

  1. 訓練60行・検証20行とIDを確認。
  2. 訓練平均が共通か確認。
  3. 両MAEをkWhで読む。
  4. 予想と実測を比べる。

表示末尾の丸め差と、内部計算の差を区別する。

最初に数値の大きさだけを見るのではなく、行の範囲から確認しましょう。表示の最後の桁に少し差がある場合は丸めの違いかもしれません。途中で平均を丸めず、内部では元の値を使います。

補足：RMSEという別の尺度

誤差を 二乗 → 平均 → 平方根。

  • 単位は元のkWhに戻る。
  • 大きいずれをMAEより強く反映する。
  • 詳細は第10回。今回はMAEが必修。
余裕があれば別の誤差尺度も紹介します。ルートエムエスイーは二乗して平均してから平方根を取ります。大きなずれを強く反映しますが、異なる尺度の数値を直接比べて優劣を決めるものではありません。
