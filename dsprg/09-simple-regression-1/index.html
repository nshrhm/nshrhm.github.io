直線の式を読む

予測値 ŷ = 切片 a + 傾き b × 入力 x

  • a：xが0のときの直線上の値（kWh）。
  • b：1時間増えると予測が何kWh増えるか。
  • bの単位は kWh/時間。

10〜25分：概念と小例

切片は直線の出発点、傾きは入力の増加に対する予測値の増え方です。係数の数字だけでなく単位も一緒に読みます。予測値は実測値とは区別します。

学習で決め、予測で使う

学生ノート§3〜6。図はクリックで拡大。

学習では訓練の稼働時間と消費電力量を使って切片と傾きを決めます。予測では決めた係数を使います。新しい入力には目的変数の実測値がなくても予測できます。

説明用の小例：ŷ = 10 + 2x

例えば切片が10、傾きが2なら、5時間の予測は20キロワット時です。入力が2時間増えると予測は4キロワット時増えます。これは考え方の小例で、配布データの答えではありません。

直線は、どう決まる？

  • 訓練点と直線の縦のずれを見る。
  • ずれを二乗して足した量を小さくする。
  • これを 最小二乗法 と呼ぶ。

今回はライブラリで実行します。

公式の導出・p値一覧は補足。

切片と傾きは適当に決めるのではなく、訓練点への当てはまりから決めます。二乗誤差の和を小さくする方法です。第8回のエムエーイーを最小にする方法だと読み替えないようにしてください。

25〜50分：主例と図

ファイル全体を実行し、先頭の読み込みから確認します。最初に係数だけを見るのではなく、訓練行の範囲を確認しましょう。主例は同じ保存名を使うので、後の実行で出力が置き換わります。

Python：二次元の入力で学習

x = train[["operating_hours"]]
y = train["energy_kwh"]
model = LinearRegression()
model.fit(x, y)
  • xは60行1列の表。
  • yは同じ60行の答え。
  • fitがmodelの係数を決める。
説明変数は一つでも二次元の表を渡します。角括弧が二重なのはそのためです。エックスとワイの行の順番を対応させます。モデルを作るだけでは学習は終わらず、フィットを呼んで係数を決めます。

R：式と訓練表を渡す

model <- lm(energy_kwh ~ operating_hours,
            data = train)
coefficients <- coef(model)
  • ~の左が答え、右が入力。
  • dataは訓練60行の表。
  • 戻り値は学習済みモデル。
エルエムへ式とデータを渡します。チルダの左に目的変数、右に説明変数を書きます。標準の設定では切片が含まれます。コエフで必要な係数を取り出します。

係数を取り出す

Python R 意味
model.intercept_ coefficients[[1]] 切片 a
model.coef_[0] coefficients[[2]] 傾き b

添字：Pythonは0から、Rは1から。

属性のintercept_に丸括弧は付けません。

Pythonは属性から、Rは係数ベクトルから値を取り出します。添字の始まりが違います。切片はキロワット時、傾きは一時間あたりのキロワット時で説明します。

Python：新しい入力を予測

queries = pd.DataFrame({
    "operating_hours": [2.0, 4.0, 6.0]})
queries["prediction_kwh"] = model.predict(
    queries[["operating_hours"]])

入力3行 → 予測3個。係数は固定。

新しい入力にも学習時と同じ列名を用います。プリディクトは各行の予測値を返します。それを予測列へ保存します。ここでフィットを追加して学習し直す必要はありません。

R：newdataを指定する

queries <- data.frame(
  operating_hours = c(2.0, 4.0, 6.0))
queries$prediction_kwh <- predict(
  model, newdata = queries)

newdataを省くと訓練行への予測になる。

Rではニューデータに予測したい入力表を指定します。省略した場合は訓練行への当てはめ値が返るため、今回の三つの入力の予測とは異なります。実測値がない入力でも予測できます。

手計算で一つ、増分でもう一つ

自分の係数を使う：

  • 5時間の予測：a + b × 5
  • 3→5時間の増分：b × 2

計算途中で係数を丸めない。

コードから独立して電卓などで確認。

係数を使って5時間の予測を計算します。次に、入力が2時間増えた場合の差を確認します。表示された係数を早い段階で一桁に丸めるとずれが生じます。どの精度で確認したかも説明してください。

照合するときの順序

  1. 元CSVと訓練IDは同じか。
  2. 入力列と目的変数は同じか。
  3. 切片・傾きが一致するか。
  4. 3・5・7時間の予測が一致するか。

末尾の丸めと、条件違いを区別。

小数表示の最後の桁だけで不一致と決めないでください。まず入力と学習条件を確認します。PythonとRの内部計算には微小な数値差があり得ますが、指定した条件で計算した値かどうかが重要です。
