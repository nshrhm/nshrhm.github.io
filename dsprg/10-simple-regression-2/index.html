評価する前に予想する

計算結果を見る前に予想します。予想が当たるかどうかだけを評価するのではありません。計算した後に、どの対象で何が変わったか説明する準備です。

残差は実測から予測を引く

残差 = 実測値 − 予測値

  • 正：予測が小さかった。
  • 負：予測が大きかった。
  • 絶対値：ずれの大きさ。

10〜25分：本文§3〜4

この教材では訓練も検証も、実測値から予測値を引いた量を残差と呼びます。検証行では予測誤差とも呼びます。符号は過大予測か過小予測かを表します。

縦方向のずれを読む

これは数値と直線を説明用に置いた概念図です。同じ稼働時間の実測が30、予測が26キロワット時なら、残差はプラス4です。横方向の距離ではなく、電力量の縦方向の差を読みます。

絶対値と二乗で相殺を防ぐ

残差がプラス3とマイナス4の小例です。絶対値を平均するとエムエーイーは3.5です。アールエムエスイーは二乗してから平均し、最後に平方根を取ります。先に平方根を取る計算ではありません。

指標の単位と分母

  • MAEもRMSEもkWh。
  • 分母は評価対象の件数n。
  • RMSEは大きいずれの影響が強い。
  • Rの残差標準誤差とは別の量。
二乗した段階の単位はキロワット時の二乗ですが、平方根で元の単位に戻ります。今回の分母は件数です。アールのサマリーに出る残差標準誤差は自由度を使うため、今回の指標とは区別します。

主例には固定の訓練結果と、今回選んだ評価結果があります。最初はどちらも訓練60行なので同じ指標になります。演習で評価対象だけを変え、訓練結果を比較の基準として残します。

Python：行ごとの残差

evaluation = train.copy()
evaluation["regression_prediction_kwh"] = model.predict(
    evaluation[["operating_hours"]])
evaluation["regression_residual_kwh"] = (
    evaluation["energy_kwh"] -
    evaluation["regression_prediction_kwh"])

同じIDの実測と予測を引く。

パイソンでは表のコピーに予測列と残差列を追加します。二重の角括弧で二次元の入力を渡します。引き算する行の対応がずれると、数値が出ても正しい残差ではありません。

Python：二乗・平均・平方根

r = evaluation["regression_residual_kwh"]
mae = r.abs().mean()
rmse = sqrt((r ** 2).mean())

from math import sqrt

本文§5：各演算の戻り値を確認。

ここでは読みやすさのため残差列をアールという変数で表しています。配布コードは同じ計算を指標表にまとめます。二乗は二つのアスタリスクです。内側から二乗、平均、平方根と読んでください。

R：同じ評価表をnewdataへ

evaluation <- train
evaluation$regression_prediction_kwh <-
    predict(model, newdata = evaluation)
evaluation$regression_residual_kwh <-
    evaluation$energy_kwh -
    evaluation$regression_prediction_kwh
アールではニュー・データへ評価表を明示します。省略すると訓練行の当てはめ値になるため、評価対象を変更したつもりでも結果が変わらないことがあります。実測と予測の件数も確認しましょう。

R：同じ定義で集計する

r <- evaluation$regression_residual_kwh
mae <- mean(abs(r))
rmse <- sqrt(mean(r ^ 2))

二乗は^。分母は対象件数。

本文§6：Pythonとの記法の違い。

アールの二乗はハット記号を使います。絶対値、平均、平方根という定義はパイソンと同じです。途中で丸めず、同じ行と定義で計算した結果を比較しましょう。

指定3行を手計算する

E004・E005・E011について：

  1. 切片＋傾き×稼働時間。
  2. 実測−予測。
  3. 絶対値と二乗。

係数を途中で丸めない。

指定した三つの行について、得られた係数を使って手計算します。予測値だけでなく、符号、絶対値、二乗も確認してください。この三行だけの平均を20行の指標と取り違えないようにします。

符号の答え合わせ

ID 予測kWh（概数） 残差kWh（概数）
E004 27.51299 −6.79299
E005 31.13182 +6.28818
E011 27.18400 −2.00400

正負は過小／過大予測を表す。

指定行の答え合わせです。イー004とイー011は予測の方が大きいため残差が負です。イー005は予測が小さいため正です。ここに示すのは表示用の概数で、内部計算は丸めていません。

指標の答え合わせ

対象 モデル MAE RMSE
訓練60 平均 6.8092 8.2781
訓練60 回帰 3.2914 3.9443
検証20 平均 7.0862 8.4193
検証20 回帰 3.6599 4.3567

単位はすべてkWh。

このデータで得られる指標です。検証20行では単回帰の方がどちらの指標も小さくなりました。訓練より検証の誤差が大きくなっていますが、これを全てのデータに必ず当てはまる規則にしてはいけません。

この比較から言えること

  • この検証20行では単回帰の誤差が小さい。
  • 同じ対象・指標で比較した結果。
  • 将来や範囲外の精度は保証しない。
  • 因果効果を示したわけではない。
結論には対象を付けて説明します。この検証20行では改善しました、と言います。別のデータや実設備でも必ず良いとはいえません。合成データ中の関係と因果効果も区別しましょう。

12時間の予測は外挿

訓練範囲は1時間から8時間です。破線は同じ直線を12時間まで延長した部分です。12時間の丸印は予測で、実測点ではありません。この範囲に実測がないため、ずれを確かめることはできません。

  • この入力の誤差は計算しない。
