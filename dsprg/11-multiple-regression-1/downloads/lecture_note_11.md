## 3 二つの入力から予測する

予測式は「予測電力量 = 切片 + 時間係数 × 稼働時間 + 処理量係数 × 処理量」です。係数は訓練60行から同時に学習します。第9回の時間係数を固定して、別に求めた処理量係数を足す方法ではありません。

- 切片の単位はkWh。両入力が0での式の値ですが、訓練範囲外なので実設備の待機電力量とは断定できません。
- 時間係数の単位はkWh/時間。**処理量を一定にしたとき**、時間が1時間増えると予測がどれだけ変わるかを表します。
- 処理量係数の単位はkWh/個。**稼働時間を一定にしたとき**、処理量が1個増えると予測がどれだけ変わるかを表します。

説明変数を追加すると、時間係数も変わり得ます。単回帰は処理量を含めずに関係をまとめ、重回帰は処理量も同時に扱うためです。係数は因果効果の証明ではありません。単位が違う係数の数値だけで「時間の方が重要」と順位付けしないでください。

## 4 Python：二列を渡す

`lesson11.py`には比較用単回帰と二変数の主例が入っています。変更対象部分は次の構造です。

```python
candidate_features = ["operating_hours", "throughput_units"]
candidate_model = LinearRegression()
candidate_model.fit(train[candidate_features], train["energy_kwh"])
print("候補 切片 kWh", candidate_model.intercept_)
print("候補 列名", candidate_features)
print("候補 係数（列名順）", candidate_model.coef_.tolist())
```

| 道具 | 目的・引数 | 戻り値・読み方 |
| --- | --- | --- |
| 文字列のリスト | 説明変数名を順番付きで指定 | `candidate_features`は列名のリスト |
| `train[candidate_features]` | 学習行から指定列を選ぶ | 60行×2列のDataFrame。未変更時は60行×1列 |
| `LinearRegression()` | 切片ありの最小二乗モデルを作る | 未学習のモデルオブジェクト |
| `fit(X,y)` | Xに説明変数表、yに同じ行の実測列を渡す | 学習済みの同じモデル |
| `intercept_` | 学習した切片を読む | 一つの数値、単位kWh |
| `coef_` | 学習した係数を読む | 入力列と同じ順番の配列 |
| `.tolist()` | 係数配列を通常のリストに変換 | 数値リスト。列名リストと対応づけて読む |
| `predict(X)` | 学習時と同じ列・順番で評価表を渡す | 行数と同じ長さの予測値配列 |

予測は`candidate_model.predict(evaluation[candidate_features])`です。学習と予測に同じリストを使うので、リストの変更が両方へ反映されます。単なる一列のSeriesではなく、二次元の表を渡します。列順を変える場合は学習・予測・係数の解釈を一緒に対応づけます。

`agg(["min", "max"])`は数値列の最小・最大をまとめた表を返し、訓練範囲の確認に使います。`pd.set_option("display.precision",17)`は表示桁を設定してNoneを返します。内部計算の精度を増やす操作ではありません。

## 5 R：式へ一項を加える

```r
candidate_formula <- energy_kwh ~ operating_hours + throughput_units
candidate_model <- lm(candidate_formula, data = train)
print(candidate_formula)
print(coef(candidate_model))
```

| 道具 | 目的・引数 | 戻り値・読み方 |
| --- | --- | --- |
| `y ~ x1 + x2` | 左辺に目的変数、右辺に説明変数を指定 | formula（式）オブジェクト |
| 式の`+` | 説明変数を別々の項として追加 | 数値を足して一列にする意味ではない |
| `lm(formula,data=...)` | 式と訓練表を渡して学習 | 学習済みlmオブジェクト。通常は切片あり |
| `coef(model)` | 学習した係数を取り出す | 名前付き数値ベクトル。`(Intercept)`は切片 |
| `predict(model,newdata=...)` | 必要列を持つ評価表を渡す | 各行の予測値ベクトル |
| `range(x)` | 数値ベクトルの最小・最大を調べる | 長さ2の数値ベクトル |

`candidate_formula`へ式を保存し、`lm`へ渡します。予測時は`predict(candidate_model,newdata=evaluation)`を使い、Rが式の列名を使います。`newdata`を省くと訓練行の当てはめ値になるため明示します。式の`*`は交互作用も含める記法なので、今回の`+`の代わりにはしません。

`options(digits=17)`は表示桁の設定です。返り値は以前の設定のリストで、ここでは設定変更という働きを使います。Python/Rとも途中で係数・予測を丸めず、末尾の小さい差と列の取り違えを区別します。

## 6 同じ行で指標と図を比べる

主例と演習は、訓練60行の結果を先に、検証20行の結果を次に表示します。各指標表は`simple`と`candidate`の2行で、`n`、`mae_kwh`、`rmse_kwh`を示します。訓練の単回帰と検証の重回帰を直接比べず、同じ分割・同じID・同じ指標で比較します。

残差は実測−予測、MAEは絶対残差の平均、RMSEは残差二乗の平均の平方根です。分母は対象件数、単位は両方kWh。Pythonの`**`とRの`^`を取り違えないでください。計算方法・描画関数・戻り値は[第10回§4〜7](review/lesson10/lecture_note_10.md)を参照してください。

主言語は`output/evaluation.csv`へ検証20行の11列を保存します。

```text
id,split,operating_hours,throughput_units,energy_kwh,
simple_prediction_kwh,candidate_prediction_kwh,
simple_residual_kwh,candidate_residual_kwh,
simple_absolute_error_kwh,candidate_absolute_error_kwh
```

元CSVの5列を保持し、予測・残差・絶対誤差を追加します。`candidate`は変更対象モデルなので、未変更時の値が単回帰と同じでも保存自体は成功します。完成答案かどうかは説明変数と結果も確認します。

`output/residuals.png`は左が比較用単回帰、右が変更対象モデルです。両方の縦軸尺度を揃え、横軸は時間、縦軸は残差kWh、破線は0です。これは二変数の予測面そのものではなく、同じ検証行の誤差を見る図です。描画用に別モデルを再学習しません。描画ひな形は完成済みで、変更不要です。

## 8 条件付きの係数を確かめる

主例の最後では稼働時間を5時間に固定し、処理量40個と80個を入力します。2つの予測の差は「処理量係数×40」です。時間も同時に変えた差を、処理量係数だけで説明してはいけません。

Pythonの`pd.DataFrame`、Rの`data.frame`へ同じ長さの列を渡し、説明用入力表を作ります。Pythonの`.iloc[0]`／`.iloc[1]`は位置0／1の値、Rの`[1]`／`[2]`は位置1／2の値を返します。ここでは同じモデルの予測値の差を計算します。この実演を演習へ追加する必要はありません。

この二つの入力に実測電力量は付けていないため、予測誤差は計算できません。各列が訓練範囲内でも、その組合せの精度が保証されるわけではありません。実設備で処理量を操作した因果効果とも区別します。
