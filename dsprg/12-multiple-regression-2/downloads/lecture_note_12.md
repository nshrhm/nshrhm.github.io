## データと三つの役割

第8〜11回と同じ架空の設備データです。`id` は行の識別子、`operating_hours` は稼働時間（時間）、`throughput_units` は処理量（個）、`energy_kwh` は消費電力量（kWh）、`split` は固定の分割ラベルです。実設備の観測ではなく、授業用の合成データです。

| 段階 | 今回の役割 | してはいけない変更 |
|---|---|---|
| 訓練60行 | 各候補の切片・係数を求める | 全80行や検証行で学習し直す |
| 検証20行 | 事前に決めた3候補を同じ行で比較する | 候補ごとに評価行や指標を変える |
| 最終確認20行 | 選択を固定した後、教員が実演する | 結果を見て候補を選び直す |

学生に配布するのは80行です。再分割しません。最終20行は配布されず、学生コードから読み込む必要もありません。

## 事前に決めた候補と選択基準

目的変数はすべて `energy_kwh`、訓練60行による切片ありの最小二乗法です。

| キー | 説明変数 | 検証MAE（kWh、概数） | 検証RMSE（kWh、概数） |
|---|---|---:|---:|
| `hours` | `operating_hours` | 3.659940 | 4.356684 |
| `throughput` | `throughput_units` | 4.482441 | 5.329957 |
| `both` | 両方 | 1.555286 | 1.759485 |

**選択基準は検証RMSEの最小値です。** MAEも併記し、異なる指標から見た誤差を確認します。今回は `both` を選びます。表の概数をコードに固定値として書かず、元CSVから計算します。計算途中の係数・予測値・指標は丸めません。

残差は「実測値−予測値」、MAEは絶対残差の平均、RMSEは残差を二乗した平均の平方根です。分母は評価対象件数です。Pythonの二乗は `** 2`、Rは `^ 2`。両指標の単位はkWhです。RMSEでは大きな残差の影響が強くなります。Rの `summary(lm(...))` の残差標準誤差とは分母が異なります。

変数を追加すれば検証性能やMAEが必ず改善するわけではありません。今回は訓練RMSEでも検証RMSEでも同じ候補が最良です。この結果を「過学習が発生した実例」とは呼びません。訓練誤差だけで選ぶ危険や、検証結果を見ながら候補や条件を何度も調整すると、その検証データへ合わせすぎる可能性を学びます。第8回から同じ検証行を繰り返し見ている点にも限界があります。

## Python：辞書から学習済みモデルを選ぶ

`lesson12.py` は完成主例です。元CSVの形・欠損、訓練／検証ID・件数、各候補の列名と係数、6行の比較表、選択候補の検証20行を順に表示します。二次元入力・`fit`・`predict` は第9・11回と同じです。

```python
features = {
    "hours": ["operating_hours"],
    "throughput": ["throughput_units"],
    "both": ["operating_hours", "throughput_units"],
}
# 完成済みのループ内で学習し、models[key] = model と保存します。
selected_key = "both"
selected_model = models[selected_key]
selected_columns = features[selected_key]
```

辞書はキーと値の組です。同じキーで「学習済みモデル」と「入力列」を対応付けます。`models["both"]` はモデルを取り出す操作であり、学習ではありません。選択後に `fit` を呼びません。

| 構文・関数 | 目的・引数 | 戻り値／結果の読み方 |
|---|---|---|
| `{キー: 値}` / `辞書[キー]` | 候補名と列・モデルを対応付ける／一つ取り出す | キーに対応する値。未知のキーはエラー |
| `features.items()` | 辞書のキーと値を順に扱う | `(key, columns)` の組。`for`で各候補に同じ処理をする |
| `models[key] = model` | 学習済みモデルを辞書に保存する | 保存だけで再学習しない |
| `list.append(辞書)` | 候補・分割・指標を1行ずつ蓄える | リストが増える。戻り値は `None` |
| `pd.DataFrame(comparison_rows)` | 行の辞書のリストを表にする | 3候補×2分割の6行。`n_features`は説明変数数 |
| `LinearRegression()` / `fit(X, y)` | 切片ありモデルを作る／訓練行で最小二乗学習 | 学習済みモデル。`X`は二次元の表 |
| `intercept_` / `coef_` | 学習済み切片／係数を読む | 列名の順序と係数配列の順序を対応させる |
| `predict(X)` | 学習済みモデルに指定列の表を渡す | 入力行に対応した予測値配列 |
| `.abs().mean()` / `sqrt((residual ** 2).mean())` | 絶対残差の平均／二乗平均の平方根 | kWh単位のスカラー。内部値を丸めない |
| `ax.bar(x, heights, width=..., label=...)` | 完成済みの棒グラフ処理。位置、高さ、幅、分割名を渡す | 棒の集合。高さはRMSE、凡例は分割 |

描画用ループや位置の調整は完成済みです。必修は選択指定の変更です。

## R：名前付きリストから学習済みモデルを選ぶ

`lesson12.R` も元CSVから独立に計算します。

```r
formulas <- list(
    hours = energy_kwh ~ operating_hours,
    throughput = energy_kwh ~ throughput_units,
    both = energy_kwh ~ operating_hours + throughput_units
)
selected_key <- "both"
selected_model <- models[[selected_key]]
```

`[[ ]]` はリストの要素そのものを取り出します。`[ ]` で一要素のリストを取り出す操作と区別します。`predict(selected_model, newdata = evaluation)` は学習済み式に対応する列を使います。ここで `lm` を呼び直しません。

| 構文・関数 | 目的・引数 | 戻り値／結果の読み方 |
|---|---|---|
| `list(hours=..., ...)` / `[[key]]` | 名前と式・モデルを対応付ける／要素を取り出す | 式または学習済みモデルそのもの |
| `names(formulas)` | リストの名前を取得する | 3候補の名前のベクトル。`for`で順に処理 |
| `lm(formulas[[key]], data=train)` | 取り出した式と訓練60行で学習 | 学習済みモデル。式の`+`は説明変数の追加 |
| `coef(model)` | 切片・係数を取得する | 名前付き数値ベクトル。名前で列を確認 |
| `predict(model, newdata=subset)` | 学習済み式に必要な列を持つ表で予測 | 入力行に対応した数値ベクトル |
| `length(リスト)` | 要素数を得て次の保存位置を作る | 整数。`length(coef(model))-1`は切片を除く係数数 |
| `if (条件) train else validation` | 分割名に応じて対象表を選ぶ | 選ばれた表。訓練モデルは変更しない |
| `do.call(rbind, comparison_rows)` | リスト内の行を縦につなぐ | 3候補×2分割の6行の表 |
| `mean(abs(residual))` / `sqrt(mean(residual ^ 2))` | MAE／RMSEを計算 | kWh単位の数値。表示と内部値を区別 |
| `geom_col(position="dodge")` | 完成済みの棒グラフ。計算済み高さを並べる | ggplotの描画層。`fill=split`で分割の凡例 |

## 独立照合と手計算

照合言語は元の80行CSVを読み直して学習します。相手のCSV・モデル・計算値を入力には使いません。候補ごとの列・切片・列名別係数、訓練／検証IDと件数、6行の指標表、選択候補、E004・E005・E011の予測・残差・絶対値を照合します。表示桁の違いだけで不一致と決めず、内部値は絶対・相対許容差 `1e-8` を目安に確認します。

E005では、稼働時間4.8時間・処理量116個を使います。表示した全桁の係数から

```text
予測 = 切片 + 時間係数 × 4.8 + 処理量係数 × 116
残差 = 実測37.42 − 予測
```

と計算し、行別出力と照合してください。選択候補の予測は約36.620440 kWhです。係数は途中で丸めません。時間係数の単位はkWh/時間、処理量係数はkWh/個です。他方を一定とした予測値の変化であり、因果効果や単位の異なる係数の大きさによる重要度順位ではありません。
