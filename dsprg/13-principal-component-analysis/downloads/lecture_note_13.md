## 3. 標準化は列ごとの操作

列平均を \(\bar{x}\)、標本標準偏差を \(s\) とすると、標準化値は \(z_i=(x_i-\bar{x})/s\) です。

\[
s=\sqrt{\frac{\sum_{i=1}^{150}(x_i-\bar{x})^2}{150-1}}
\]

列ごとに平均を引き、標準偏差で割ります。行ごとに4値の平均を引く操作ではありません。標準化後の列平均はほぼ0、標本標準偏差はほぼ1です。浮動小数点計算なので平均が小さなゼロでない値になる場合があります。

すべてcmでも、列のばらつきの大きさは異なります。標準化は各列の尺度を揃える選択です。必ず優れた分析になるという規則ではありません。標準化なしの場合も、今回のPCAは中心化（列平均を引く操作）を行います。

## 4. 係数・得点・寄与率を分けて読む

- **係数（重み）**: 元の4列をどう組み合わせるか。係数表は4行×2列です。行が測定値、列がPC1・PC2です。
- **主成分得点**: 各花の新しい座標。150行×2列です。IDを付けて元の花と対応させます。
- **寄与率**: 中心化・標準化という条件の下で、全4成分の分散のうち各成分が占める割合です。

標準化後のPC1得点は、4つの標準化値とPC1係数を掛けて合計したものです。PC1は最大の分散を表す方向、PC2はPC1と直交する方向のうち次に大きい分散を表します。係数の絶対値だけで原因や予測上の重要度を断定しません。

寄与率の分母をPC1・PC2だけの分散にすると、2成分の累積が必ず1になってしまいます。**分母は全4成分の分散合計**です。計算結果を表示のために丸めても、その丸めた値を後続の計算へ戻しません。

## 5. Python主例を読む

`lesson13.py`を既存Pythonタスクで実行します。CSV確認、ID・件数、平均・標準偏差、比較用と変更対象のPCA、係数・寄与率・得点、保存先の順に表示されます。

```python
X = data[features]
means = X.mean()
sample_sd = X.std(ddof=1)
inputs = (X - means) / sample_sd if scaled else X
model = PCA(n_components=2, svd_solver="full", whiten=False)
coordinates = model.fit_transform(inputs)
```

| 構文・関数 | 目的・引数 | 戻り値と読み方 |
| --- | --- | --- |
| `data[features]` | 指定した4列を同じ順序で選ぶ | 150×4のDataFrame。id/speciesがないことを確認 |
| `X.mean()` | 各列の平均。既定は列方向 | 列名付きの4値。単位cm |
| `X.std(ddof=1)` | 各列の標本標準偏差。分母は件数−1 | 列名付き4値。単位cm。`ddof=0`とは異なる |
| `a if scaled else b` | 真ならa、偽ならbを選ぶ | 今回は標準化した表、または元の4列表 |
| `PCA(...)` | 2成分を保持、完全SVD、白色化なし | 計算条件を持つモデル。作っただけでは未学習 |
| `fit_transform(inputs)` | 入力から軸を学習し、その入力の得点を求める | 150×2の配列。列順はPC1、PC2 |
| `model.components_` | 学習済みの主成分係数 | 2×4。`.T`で4×2にし元の列名を行へ対応付ける |
| `model.explained_variance_ratio_` | 全分散に対する各成分の割合 | PC1、PC2の2値。合計が1とは限らない |
| `ratios.cumsum()` | 前から順に足す | PC1、PC1+PC2の累積寄与率 |
| `scores.insert(0, "id", ...)` | 得点表の先頭にIDを挿入 | 表をその場で変更。返り値を表に代入しない |

`PCA`は中心化しますが、自動で標準偏差を1に揃えません。明示的な標準化部分が必要です。[Python公式](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)

既習の辞書`results`には`baseline`と`candidate`の計算結果を保存します。`results["candidate"]`は計算済みの結果を取り出します。描画のために別モデルを学習しません。

## 6. R主例を読む

`lesson13.R`を既存Rタスクで実行します。

```r
model <- prcomp(X, center = TRUE, scale. = scaled)
weights <- model$rotation[, 1:2, drop = FALSE]
all_ratios <- model$sdev^2 / sum(model$sdev^2)
ratios <- all_ratios[1:2]
```

| 構文・関数 | 目的・引数 | 戻り値と読み方 |
| --- | --- | --- |
| `colMeans(X)` | 数値表の各列平均 | 列名付き4値。cm |
| `sapply(X, sd)` | 各列に標本標準偏差`sd`を適用 | 列名付き4値。`sd`の分母はn−1 |
| `prcomp(X, center=TRUE, scale.=scaled)` | 中心化し、指定時は列の標本標準偏差で割ってPCA | 係数・得点・標準偏差などを持つリスト形式の結果 |
| `model$rotation` | 各主成分の係数 | 元の4列×4成分の行列。行名が元の列名 |
| `[, 1:2, drop=FALSE]` | 全行と上位2成分を選択 | 4×2の行列。`drop=FALSE`は行列の形を保持 |
| `model$x` | 中心化・必要時標準化した入力の主成分得点 | 150×4。今回は先頭2列を使う |
| `model$sdev` | 各主成分の標準偏差 | 4値。二乗すると各成分の分散 |
| `sdev^2 / sum(sdev^2)` | 全4成分を分母として寄与率を求める | 4値。`[1:2]`は計算した後で選択 |
| `cumsum(ratios)` | 累積和 | PC1、PC1+PC2の累積寄与率 |

`scale.`の末尾の点を含めて引数名です。Pythonの係数配列とは向きが違うため、**列名を付けた係数表**で比較します。[R公式](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/prcomp.html)

`results[["candidate"]]`は名前付きリストから計算済みの結果を取り出します。`do.call(rbind, variance_tables)`は2つの寄与率表を縦に連結します。これらの選択・表の連結は[第12回](https://nshrhm.github.io/dsprg/12-multiple-regression-2/)と同じ考え方です。

## 8. 寄与率と散布図の読み方

| 条件 | PC1 | PC2 | 累積 |
| --- | ---: | ---: | ---: |
| 標準化なし | 0.924619 | 0.053066 | 0.977685 |
| 標準化あり | 0.729624 | 0.228508 | 0.958132 |

これらは表示用の概数です。標準化後の2次元は、標準化した4列の全分散の約95.81%を保持します。残り約4.19%を表示していません。「95.81%の花を正しく分類した」という意味ではありません。

標準化すると今回の累積寄与率は下がります。しかし標準化前後で分散の基準自体が変わっています。寄与率が高い方を無条件に優れた分析としません。同じcmでも、ばらつきの大きい列の影響をそのまま残すか、揃えるかという問いです。

図の左は比較用、右は変更対象です。軸はPC1・PC2で、元の花びら長そのものではありません。標準化なしの得点の単位はcm、標準化後は無次元です。各パネルの縦横の1単位の長さを揃えますが、条件間で数値範囲を共通にする必要はありません。

## 9. 言語間照合と手計算

**主成分の係数と得点は、主成分ごとに全体の符号が反転しても同じ解です。** PC1の係数4個をすべて−1倍にすると、PC1得点150個もすべて−1倍になります。図は左右反転しますが、距離や寄与率は変わりません。PC2も同様です。一部の行だけの符号変更や、係数だけの反転は別の結果です。

比較する順序は、入力IDと150行→4列→平均とn−1標準偏差→寄与率→列名付き係数→符号を揃えた得点です。I001・I051・I101を確認します。符号合わせは一つの成分に同じ±1を適用します。各値の絶対値だけを比較すると誤りを見逃します。

I001のがく片長は5.1 cm。列平均約5.843333333333333、標本標準偏差約0.828066127977863から、標準化値は約−0.897674です。符号を含めて確認してください。

I001のPC1は、表示した4つの標準化値に、その言語で得たPC1の係数を掛けて合計します。途中の値を丸めずに計算します。通常の表示桁が足りないときはPythonで`print(value.to_string(float_format=lambda v: format(v, ".15g")))`、Rで`print(value, digits=15)`のように表示精度を増やせます。表示精度を増やしても元の計算結果は変わりません。

符号の決め方によってI001のPC1は約−2.257141または約+2.257141になります。自分の係数と同じ向きの得点になることが確認点です。
