# 第13回の復習: 標準化とPCA

irisの4測定値から、IDと種類を除いて計算します。標準化は列平均を引き、分母n−1の標本標準偏差で割る操作です。値は無次元になります。

PythonのPCA自体は尺度を標準化しません。明示的に標準化した表にPCA(n_components=2, svd_solver="full", whiten=False)を使います。Rではprcompによって計算し、標準化済みの表にはscale.=FALSEを指定して二重に割らないようにします。

係数は4測定値と主成分との対応、得点は各行の座標です。寄与率は保持した分散の割合で、分類精度ではありません。成分の係数と全行の得点を一緒に符号反転しても同じ解です。第14回は4列で群分けし、PCAの上位2成分を図にだけ使います。
