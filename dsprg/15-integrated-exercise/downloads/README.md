# 第15回 後半総合演習

ZIPを展開した `lesson15` フォルダーを、既存の `work/exercises/` へ置きます。
VS Codeでは `work` 全体を開き、登録済みのPython／R実行タスクを使います。

[学生本文](lecture_note_15.md)を読み、AまたはBの一経路だけを選びます。
主例は各経路の `lesson15.py` / `lesson15.R`、変更する主言語は `exercise15.py` / `exercise15.R`、他方は `verify.py` / `verify.R` です。
未変更ひな形も実行できますが、必須変更を終えるまで課題完成にはなりません。

- A：説明変数へ処理量を追加。保存先 `work/exercises/lesson15/output/A/`。
- B：変更対象の群数を2から3へ。保存先 `work/exercises/lesson15/output/B/`。

主言語が `analysis.csv` と `figure.png` を保存します。照合言語は保存しません。
空のレポートひな形は `templates/report_A.md` / `.docx` と `report_B.md` / `.docx`。
Word等で編集してPDF化できます。Markdownの場合も図を挿入してPDF化してください。
PDF・CSV・PNGはClassroom、両コード全文・経路・主言語・提出版はFormsへ提出します。
締切・正式配点・実Forms URLは担当教員の案内を確認してください。
