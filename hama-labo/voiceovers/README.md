# 音声とナレーションの対応

54枚すべての `slide.md` に、非空の複数行 `<aside class="notes">` と音声参照があります。語りは日本語、「僕」のLT風です。ノートは自由な寄り道を前提に、各ページだけでも話せるように書いています。

今回の制作ではMP3を生成していません。作業中に別作業で54件追加されたことを確認し、その音声は変更していません。以下の54件が現在存在しますが、再生とナレーションとの一致は未確認です。

```text
slide_01.mp3
...
slide_54.mp3
```

参照は `./voiceovers/slide_NN.mp3`。基本01〜18、寄り道19〜50、出典51〜54の各位置と、音声番号が一対一に対応します。

スライドを挿入・削除・並べ替えた場合、後続の音声番号を全て更新して構造監査を再実行してから生成してください。ノートの意味と話し方も、音声化する前に先生が確認できます。

```sh
make -C presentation check
# 別途音声を生成した後
make -C presentation audit-audio
```

ファイルの存在確認と、実際に再生できること・ノートに一致することの確認は別です。

少なくとも06と08は、音声ファイルの追加後にナレーションを調整しました。06は先生固有の呼び方を断定する文を修正、08は公開入口が既存研究の参加案内であることを反映しています。該当音声との対応確認、必要に応じた別途の再生成が必要です。音声ファイルを勝手に更新せず、`../validation/audio-observed.json` に観察時のハッシュと理由を記録しました。
