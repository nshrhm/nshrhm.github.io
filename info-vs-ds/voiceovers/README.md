# Voiceover contract

このプレゼンテーションは全28枚です。各MP3は、同じ位置にあるスライドと一対一で対応します。

期待するファイル名は、ゼロ埋めされた連番です。

```text
slide_01.mp3
...
slide_28.mp3
```

各スライドは `./voiceovers/slide_XX.mp3` を参照し、読み上げ元となる日本語の `<aside class="notes">...</aside>` を一つ含みます。現時点では `slide_01.mp3` から `slide_28.mp3` までの28ファイルがすべて存在します。今回の整理作業ではMP3を生成・変更していません。

スライドを挿入、削除、並べ替えた場合は、音声を生成する前に、その位置以降の参照番号をすべて振り直し、構造監査を再実行してください。付録もスライド数と音声番号に含みます。
