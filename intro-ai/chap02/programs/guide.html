入力とコードを一段ずつ追う（プログラム改訂版）

Notebookの先頭に、入力→途中計算→結果→一条件の変更を追う節を追加しました。初回は既存venvのカーネルで再起動→全セル実行。その後、一節ずつ予想してからShift+Enterで実行します。関数の定義セルは計算方法を登録し、次の短い実行セルが値を表示します。表示専用の補助コードは変更不要です。

成功の目印：母が心配ですでは母の規則が先に一致し、既定cycleでは6回目にオウム返し。固定20応答は従来どおり。

文字列と規則の一致

予想：どの規則が先に一致するか。

操作：example_textを’母が心配です’から’試験が心配です’へ変更し、同じセルを実行します。

結果確認：母の規則で停止し、心配の規則まで進まない。

理由を説明：未確認と不一致の違い。

復帰：example_text=’母が心配です’に戻して再実行します。

規則の並べ替え

予想：複数の語があると何を採用するか。

操作：example_reverseをFalseからTrueへ変更し、同じセルを実行します。

結果確認：通常は先生、逆順は母。

理由を説明：規則の変更と機械学習の違い。

復帰：example_reverse=Falseに戻して再実行します。

回数を持つ応答

予想：countはいつ増えるか。

操作：example_cycleを5から2へ変更し、同じセルを実行します。

結果確認：判定前と更新後を8件の表で追える。

理由を説明：countとturnsの違い。

復帰：example_cycle=5に戻して再実行します。

Python版もpython doctor.py --explain allで同じ入力・途中計算・結果を表示します。テーマごとの指定は--explain rule、--explain order、--explain cycleです。既存の基準実行とJSON出力は維持しています。

図表は実際の計算から得た値を表示し、小数の丸めは表示に限ります。見返すだけで元データを書き換えません。変更したセルを初期値へ戻して再実行し、実行順が分からなくなったらカーネルを再起動して全セル実行します。同梱Pythonをimportしない単独Notebookです。依存の初回導入を除き計算中の通信は不要です。

Python ／ Notebook ／ 一式ZIPを保存

保存して実行する

ZIPを保存し、新しいフォルダーへ展開します。授業で使用しているvenvを有効化し、python --version と python -c "import sys; print(sys.executable)" で環境を確認します。コードはPython 3.10以降の標準ライブラリで動きます。

python doctor.py --demo

固定20入力への応答が表示されます。初回「先生に相談したいです」への応答は「私のことでなくあなたのことを話しましょう」です。対話入力で試す場合は python doctor.py。20応答で終了し、入力終了やCtrl+Cでも終了できます。

Notebook

既存の授業用venvをVS CodeのNotebook右上のカーネルで選び、カーネル再起動→全セル実行を行います。Notebookは単体で動き、同梱Pythonのimportや外部APIを必要としません。固定20件と変更例が出れば成功です。

Notebook環境が不足する場合だけ、venv有効化後に python -m pip install -r requirements.txt。導入にはネット接続が必要です。uvを使う制作環境では元のプログラムフォルダーで uv sync --locked、uv run --locked python doctor.py --demo でも実行できます。学生にuvや制作用Python版は要求しません。

一つ変えて戻す

元データを残し、RULES のコピーで「が心配です」を先頭にすると「母が心配です」への応答が変わります。比較ごとに新しい Doctor() を作り、対話状態をそろえます。規則を人が変えたので、自動学習ではありません。

周期5なら6・11・16回目がオウム返しです。Doctor(cycle=2) では3・5回目から変わります。ノートブックを最初から実行し直せば基準条件へ戻ります。元のZIPを残しておくと改変前へ復帰できます。

困ったとき

python が見つからなければ授業用venvを確認します。Notebookのimportエラーはカーネルの環境を確認します。応答が違う場合は入力文字、規則順、対話回数の順で確認します。空欄を埋める未完成プログラムではありません。受講者の実機や理解度の確認は技術検証とは別です。

段階表示とコードを対応させる

操作教材の「計算の内訳・確かめること」を開き、入力と同じ順序で途中の値を比較します。説明の前後移動では計算は進みません。プログラム側では同じ固定入力と条件でセルを実行し、表示の丸めによる末尾の差と、計算条件の違いを区別してください。

ブラウザーの規則順・応答前カウンタ・採用規則・応答後カウンタを、Doctor.respondの分岐と対応付けます。周期5の6・11・16回目を特に確認してください。

Python／Notebookの計算コード・固定データ・期待値は変更していません。変更実験は元データのコピーで行い、再実行前には説明済みの初期化手順を使います。
