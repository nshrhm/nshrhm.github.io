第3回 分類と汎化：保存と実行

Python・Notebookを同じフォルダーへ保存します。入力は架空の固定データです。学習8件、検証4件、テスト4件の役割を変えずに実行しましょう。

開始と成功の目印

授業のvenvを有効にして python generalization.py --demo を実行します。Python 3.10以降の標準ライブラリで動きます。既存のuv環境なら uv run python generalization.py --demo でも実行できます。

Notebookは授業のvenvをカーネルに選び、再起動して全セルを実行します。Jupyterがなければvenv内で python -m pip install -r requirements.txt を実行してください。同梱Pythonのimportや外部データの取得は不要です。

基準結果はしきい値25、学習7/8・検証3/4・テスト3/4。記憶モデルは学習8/8・検証2/4・テスト2/4です。学習用だけで二つのモデルを作り、検証でしきい値モデルを選んで固定してからテストします。テストを見て選び直しません。

入力・途中の判定・正解数を対応させる

操作教材の「学習の流れ」で学習→検証→選択固定→テストへ進みます。例えば検証のx=35は25以上なので予測1ですが、正解は0です。4件の○を数えると3件、正解率は3÷4=75%です。正解ラベルは採点に使い、推論の入力には渡しません。

学習データのコピーでtr03のラベルを変更し、しきい値候補の誤り数を比較してから再学習します。入力xだけを24→25へ変える実験とは区別してください。計算は正確な分数を用い、件数・予測は完全一致で照合します。

戻す・困ったとき

変更前のファイルを保存し、変更はコピーで行います。復帰は元ファイルを開き、Notebookのカーネルを再起動して全セル実行です。途中セルだけの再実行で状態を混ぜないようにします。ファイルが見つからないときは保存フォルダー、モジュールのエラーでは選択したvenv・カーネルを確認してください。
