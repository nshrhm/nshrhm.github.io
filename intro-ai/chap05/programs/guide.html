演習スライド ／ 図解教材 ／ 図解教材の使い方

1．保存して、学ぶ準備をする

この演習では、固定したニューラルネットワーク、重みの1回更新、RNNの状態、SOMの近傍更新を使います。答えを予想し、実行し、一つ変えた結果の理由を説明することが目標です。

Notebookを保存 ／ Python版を保存 ／ 一式ZIPを保存

Notebookを中心に進めます。ZIPにはNotebook・Python版・このマニュアル・Notebook用requirementsを収録しています。ZIPを使う場合は先に展開してください。Notebookは単体で動き、隣のPythonファイルやJSONファイルを読み込む必要はありません。

ファイルを授業用フォルダーに保存します。ブラウザーの画面で読むだけではPythonは実行されません。GitHub Pagesではファイルを配布し、実行は自分のPCのVS Codeで行います。 図解教材はブラウザーだけで操作できます。

2．VS Codeとカーネルを確認する

  1. これまでの授業で使ったVS CodeとPython環境を開きます。WSLを使っている場合は、VS CodeがそのWSLへ接続していることを確認します。
  2. 保存した neuralnet.ipynb を開きます。WSLを使う場合は、授業で使っているWSL側のフォルダーへファイルを置きます。
  3. 右上の「カーネルの選択」で、授業用venvのPythonを選びます。すでに登録済みなら「AI course」など授業で使ったカーネルを選びます。
  4. 「カーネルの再起動」の後、「すべて実行」を選びます。

カーネルはセルのPythonを実行する環境です。ノートの内容だけを表示する画面とは役割が異なります。授業用venvを再利用し、この演習のために別のPythonを入れ直す必要はありません。コード本体はPython 3.10以降の標準ライブラリだけを使います。

Pythonのパスが授業用venvを指していない場合は、インストールへ進まず環境を確認してください。登録後にカーネル選択を開き直します。ダウンロード名の末尾が .ipynb.txt になっていないかも確認します。

3．基準の結果を読む

学習目標は、順方向の計算、重みの更新、RNNの状態、SOMの代表ベクトルを区別して説明することです。掛け算・足し算と表を読むところから始め、微分やPython文法の暗記は前提にしません。

Notebookの「基準結果」を読み、その直後のセルの出力を確かめます。最初は入力もコードも変更しません。

観察するもの 成功の目印 何を意味するか
固定XORの4入力 出力が0, 1, 1, 0 重みを固定した計算。学習の成功を示す結果ではない
1回の勾配更新 損失0.5 → 0.125 初期重み2を1.75に変えた結果
RNN [1,0]で状態[1,0.5]、[0,1]で[0,1] 同じ重みでも入力順が違えば最後の状態が変わる
SOM A(0.5,0)、B(1.75,1.5)、C(4,0) 勝者Aと地図上で隣接するBが1回更新される

XORでは入力 (0,0), (0,1), (1,0), (1,1) の順です。hidden_u は中間層の総入力、hidden はその出力、output_u は出力層の総入力、output が最終出力です。ステップ関数は総入力が0でも1を返します。

gradient の loss_before と loss_after を比較します。rnn_10 と rnn_01 はそれぞれ初期状態0から計算します。som の winner は0始まりなので0がA、squared_distances は入力空間の距離の二乗、updated は更新後の代表ベクトルです。

4．予想して、一つ変えて比較する

Notebookの「実験1〜4」に実行セルがあります。下のコードを追加セルに貼り付けても同じ比較ができます。先に「計算の定義」と「基準結果」まで実行してください。毎回同じ初期入力を使い、元の定数やベクトルは上書きしません。

実験1：しきい値だけを変える

問い・予想： 入力(1,0)で、中間h₁のしきい値を−2にすると、出力はどう変わるでしょうか。

trial_thresholds = list(HIDDEN_THRESHOLDS)
trial_thresholds[0] = -2
before_xor = forward((1, 0))
after_xor = forward((1, 0), hidden_thresholds=trial_thresholds)
print("変更前:", before_xor)
print("変更後:", after_xor)
print("元のしきい値:", HIDDEN_THRESHOLDS)

結果： h₁の総入力は−1→0、最終出力は1→0です。説明する問い： 境界0でステップ関数が1になることは、どの中間出力を変えましたか。

実験2：学習率を変える

問い・予想： 学習率を大きくすれば、必ず損失は小さくなるでしょうか。

small_rate = gradient_step(rate=0.125)
large_rate = gradient_step(rate=1)
print("学習率0.125:", small_rate)
print("学習率1:", large_rate)

結果： 同じ初期損失0.5から、更新後は0.125と4.5になります。説明する問い： 勾配が同じでも、更新幅が大きすぎると何が起きますか。Notebookの2段計算は、更新前に両方の勾配を求めてから同時更新する別の確認例です。

実験3：系列の順序を変える

問い・予想： 同じ二つの値を逆の順に入れても、最後の状態は同じでしょうか。

states_10 = recurrent_states([1, 0])
states_01 = recurrent_states([0, 1])
print("[1,0]の状態:", states_10)
print("[0,1]の状態:", states_01)
print("前の状態を使わない:", recurrent_states([1, 0], recurrent_weight=0))

結果： 最後の状態は0.5と1です。呼び出すたび初期状態0から始まります。説明する問い： 変わったのは入力順・状態・重みのどれですか。これはRNNの重みを学習する実験ではありません。

実験4：SOMの近傍を変える

問い・予想： 勝者だけを更新すると、隣接Bは動くでしょうか。

trial_sample = [1, 0]
original_prototypes = [[0, 0], [2, 2], [4, 0]]
with_neighbor = som_step(trial_sample, [p[:] for p in original_prototypes])
winner_only = som_step(trial_sample, [p[:] for p in original_prototypes], neighbor_factor=0)
print("近傍あり:", with_neighbor)
print("勝者だけ:", winner_only)
print("元の代表ベクトル:", original_prototypes)

結果： 勝者Aはどちらも(0.5,0)。Bは近傍ありで(1.75,1.5)、近傍なしで元の(2,2)です。変更する neighbor_factor は0.5→0。学習率0.5×近傍係数0.5＝Bの実際の更新係数0.25なので、この二つの係数を区別してください。

説明する問い： 勝者を選ぶ入力空間の距離と、地図A—B—Cの隣接は同じ意味でしょうか。これは反復学習全体ではなく1回の更新です。

XOR、勾配と更新、RNN、SOMで同じ条件を操作し、Notebookの結果と比べます。

6．元に戻す・困ったとき

  • 基準を再確認するときはカーネルを再起動して全セルを実行します。自分で変更した実験値は元の値へ戻すか、追加した実験セルを実行対象から外します。再起動だけでは編集したコードは元に戻りません。
  • 関数や定数まで編集して戻せない場合は、作業を別名で保存してから配布Notebookをもう一度保存します。
  • NameError は定義セルを飛ばしていないか確認します。上から順に実行し、使い方の例は定義の後の新しいコードセルへ貼り付けます。
  • カーネルが止まった場合は再起動します。Python版ではファイルを保存したフォルダーと有効なvenvを確認してください。
  • guide.html はZIP内でオフライン閲覧できます。同梱していない図解教材・スライドへ移動する場合はネット接続が必要です。
