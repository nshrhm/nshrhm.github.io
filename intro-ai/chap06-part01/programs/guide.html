第7回 CNN：プログラムの保存・実行・学び方

スライド ／ 操作教材 ／ 操作マニュアル

何を学ぶか

4×4の人工画像から、畳み込み→ReLU→プーリング→分類までの値を追います。続いて、小さなCNNの学習前後を比べます。問いは「学習用の画像で成功したら、別の位置の線でも成功するか」です。GPU、外部画像、PyTorchは使いません。Python版の計算には標準ライブラリだけを使います。

保存して開始する

Notebookを保存 ／ Python版を保存 ／ Notebook用依存一覧を保存 ／ 一式ZIPを保存

  1. ZIPを展開するか、Notebookを作業フォルダーに保存します。
  2. VS CodeでNotebookを開きます。Python・Jupyter拡張機能を使用します。
  3. 右上のカーネル選択から、これまで使っているvenvのPythonを選びます。制作用Python 3.14に合わせる必要はありません。教材コードの対象はPython 3.10以降です。
  4. カーネルを再起動し、「すべて実行」を選びます。初回はコードを変更しません。
  5. 「基準結果」の畳み込み1行目 [-2,2,0] と損失約 0.130153 を確認します。

NotebookはPythonファイルをimportしないので、Notebook一つでも実行できます。実行前に必要な環境を整えれば、計算中の通信は不要です。

カーネルが見つからないとき

既存venvを有効化したターミナルで python --version を確認します。Notebook用パッケージがなければ、そのvenv内で次を実行します。

python -m pip install -r requirements.txt

その後、VS CodeでPython環境とNotebookカーネルを選び直します。環境がない場合は作業フォルダーで python -m venv .venv を実行し、Windowsなら .venv\Scripts\activate、macOS/Linuxなら source .venv/bin/activate で有効化します。システム全体へインストールする必要はありません。

出力と概念の対応

出力 読み方・基準結果
convolution 3×3の積和。各行[-2,2,0]
relu 負の値を0へ。各行[0,2,0]
stride2 移動幅2。2×2で各行[-2,0]
max_pool / mean_pool 同じ2×2領域の最大2／平均1
loss_before / loss_after 学習用平均損失：約0.765126→0.130153
train_before / train_after 学習用予測：[1,1,1,0]→[0,0,1,1]
heldout_after 確認用予測：[1,1,1,1]。端の縦線を誤分類

ラベル0は縦線、1は横線。並びは縦の2位置、横の2位置です。正解は両集合とも [0,0,1,1]。学習用は位置1・2、確認用は位置0・3で、位置は0始まりです。確認用画像は重み更新に使いません。

学習は2×2フィルター2枚とバイアス、全結合層を合わせた28パラメーターです。ReLUの後に2×2・移動幅1の最大プーリングを適用し、8値から2スコアを作ります。softmaxは最大スコアを引いて計算し、同じ値ならラベル0を選びます。

一つ変えて比べる

基準データを直接上書きせず、各実験セルに用意したコピーを使います。実行前の予想と、実行後の説明を一組にします。

セル 変えるもの 期待結果 説明する問い
実験A signを1と-1で比較 [-2,2,0]が[2,-2,0]に ReLUの後は何が残る？
実験B trial_strideを1と2で比較 3×3から2×2に どの位置を計算しなくなった？
実験C trial_modeをmaxとmeanで比較 2から1に 強い応答と領域平均はどう違う？
実験D trial_rateを0と0.1で比較 0なら重み・損失は不変 学習用の成功だけで十分？

実験Dの train は呼ぶたびに初期値をコピーします。学習済みの重みを続けて更新する比較ではありません。「学習前後」のセルでは初期フィルターと更新後フィルター、画像ごとの正解・予測も見られます。

元に戻す・困ったとき

  • 実行順が分からない、NameError：カーネルを再起動して全セル実行します。
  • 値が基準と違う：変更したセル、フィルター、位置、学習率を確認します。配布Notebookを別名で再保存して比較できます。
  • ModuleNotFoundError：選択中のカーネルが、依存を入れたvenvと同じか確認します。
  • 計算中：実行完了を待ちます。止めた場合はカーネル再起動からやり直します。
  • ダウンロードが文字表示になる：リンクを右クリックして保存し、.ipynb／.py の拡張子を保ちます。
  • 保存HTMLから他教材へ進めない：公開サイトの 第7回スライドを開きます。

Python版で実行する

venvを有効化し、保存したフォルダーで実行します。

python cnn_basics.py --demo

JSONだけを表示する場合は --json を追加します。Notebookと同じ基準値が表示されます。uvを使う人は補足として uv run --no-project python cnn_basics.py --demo でも実行できます。

計算条件と限界

人工画像8枚だけの教材です。初期値はPythonのseed 42から固定し、学習率0.1・100回・4画像の全件一括更新を使います。中央差分の幅は1e-6。ReLUの0や最大値の同値付近では勾配近似に注意が必要です。大規模CNNで通常使う誤差逆伝播より計算量が多い方法なので、小例に限っています。

表示する基準JSONは小数6桁です。学習用画像の成功は実写真の認識性能を意味しません。最後に「変えた条件・予想・結果・根拠」を説明しましょう。
