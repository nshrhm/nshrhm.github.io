第8回 深層学習2：Python／Notebook解説

学習目標と保存

自己符号化器の再構成誤差、LSTMのセル状態と出力、GANの交互更新を再現し、一つの条件を変えて説明します。第6・7回のニューロン・損失・状態の考え方と、Pythonの変数・リスト・関数を使います。処理コードの全てを一度に書き直す必要はありません。

Notebookを保存 ／ Pythonを保存 ／ 一式ZIPを保存

スライド ／ 操作教材 ／ 操作マニュアル

ZIPを自分の学習用フォルダーへ保存し、展開します。中にはPython、Notebook、このHTML解説、環境用のrequirements.txtがあります。元のZIP・Notebookを基準版として残し、編集する時はコピーを作ってください。第8回は未公開のローカル確認版です。ZIP内で同梱外教材へのリンクが使えない時は、元のプレビュー画面へ戻ります。

計算はPython標準ライブラリのみです。外部データ・APIキー・GPU・PyTorchは不要です。Python 3.10以降を想定し、制作用のPython 3.14を要求しません。Notebookの実行にはJupyterカーネルが必要です。

既存venvとカーネルを選ぶ

  1. VS Codeで展開したフォルダーを開きます。
  2. ターミナルで、授業で用意したvenvを有効化します。Windowsでは既存venvの Scripts\activate、macOS／Linuxでは source .venv/bin/activate が一般的な例です。自分の環境の場所を指定します。
  3. python -c "import sys; print(sys.executable)" で、使用するPythonがvenv内か確認します。
  4. Notebook右上のカーネル選択で、その環境を選びます。ipykernelがなければ、選んだvenv内で python -m pip install ipykernel を実行します。システムPythonへ追加しません。
  5. カーネルを再起動して「すべて実行」を選びます。途中のセルだけを先に実行しないでください。

Notebookは単体で動き、同梱Pythonをimportしません。コードセルには必要な関数を収録しています。パッケージ準備後の教材計算はオフラインで実行できます。requirements.txtは制作時のNotebook環境の記録です。既存の実行環境がある場合に、全パッケージを入れ直す必要はありません。

入力と計算条件

  • 自己符号化器：5成分のうち1成分だけが1の人工データ5行。入力と目標は同じ。5→3→5構造、sigmoid、全25成分のMSE、学習率4、シード65535、1,000回。シードから初期値を作る32bit LCGは教材の再現用です。
  • LSTM：手動ゲートの初期値は前のc=1、f=0.8、i=0.5、g=0.6、o=0.75。系列の理想化例は初期c=0、i=o=1、候補[1,0,0,0]、f=0.8です。
  • 固定重みLSTM：f=σ(0.5x+0.2h前+1)、i=σ(x−0.1h前)、g=tanh(x+0.3h前)、o=σ(0.4x+0.1h前)。説明用の未学習の係数です。
  • GAN：実データ[1,2,3]、ノイズ[−1,0,1]。G(z)=az+b、D(x)=σ(wx+d)。初期(a,b,w,d)=(0.5,−1,1,0)。学習率0.1でD→Gを1回ずつ更新します。

入力は全て授業用の人工データで、実際の画像や文章の性能を検証するものではありません。

一つ変更する6実験

Notebookの各「変更実験」セルを使います。元の DATA・GAN_INITIAL・baseline_result を変更せず、コピーや別変数に結果を保存します。

セル 予想・操作 想定結果・説明する問い
変更実験1：入力 trial_x = DATA[1][:] を固定初期重みへ入力 元の5行は不変。中間表現と再構成は最初の入力と異なる。どの入力を変えたか？
変更実験2：回数 trial_fit = train_autoencoder(2000) MSE≈0.001924。同じ初期値で回数だけ比較できているか？
変更実験3：出力ゲート trial_gate = gate_step(output_gate=0) h=0、c=1.1。出力を抑えることと忘れることの違いは？
変更実験4：順序 候補のコピーを逆順にする 最後のc=1。書き込んだ後に何回fを掛けたか？
変更実験5：生成器 trial_params のbだけ0へ変更し、z=0で計算 G(0)=0、D(G(0))=0.5。これは手動変更で、学習ではない。
変更実験6：学習率 GANの学習率を0としてD→Gを更新 a,b,w,dが全て初期値のまま。更新式のどこが0になったか？

予想を自分のメモに書いてからセルを実行し、基準値との違いを説明します。試す値をさらに変える場合も、一つずつ変更してください。自己符号化器の回数は0〜4,000の整数、学習率は0〜4です。ゲートは0〜1、候補は−1〜1、GANの学習率は0〜1です。

Python版を実行する

venvを有効にしたターミナルで、保存したファイルのフォルダーから実行します。

python deep_learning2.py --demo
python deep_learning2.py --demo --json

前者は説明と基準結果、後者は照合用JSONを表示します。演習の値を変更する場合はNotebookの変更実験セルを使うと、基準結果を残して比較できます。

uvを利用する場合の補足（uvの利用は必須ではありません）：

uv run --no-project python deep_learning2.py --demo

元に戻す・困ったとき

  • NameError：先に定義するセルが未実行です。カーネルを再起動し、上から全セル実行します。
  • importエラー・カーネルが見つからない：Pythonの場所とNotebookのカーネルを確認します。Notebook環境を整える場合は選んだvenvへipykernelを追加します。
  • ファイルが見つからない：ZIPを展開し、ターミナルの作業フォルダーを確認します。Notebook単体の計算には同梱ファイルは不要です。
  • 基準値が違う：基準データ・初期値・学習回数を変更していないか確認します。元のZIPから新しいフォルダーへ展開し、再起動・全セル実行します。
  • 操作画面と微小に違う：表示の丸めを確認します。内部数値は絶対・相対許容誤差1e−9で照合し、基準JSONは6桁で比較しています。
  • 元へ戻す：編集用コピーを閉じ、保持した元のNotebookを開きます。再起動だけでは編集したソースは元に戻りません。

教室や学生の端末での実行結果と、制作者のローカル実行確認は別に記録します。

段階表示とプログラムの対応

操作教材の「計算の内訳・確かめること」を開き、符号化の重み・復号の重み・同じ位置の二乗誤差をコードの出力と比較します。スライドは小数4〜6桁、操作教材は6桁の表示で、プログラムの計算精度とは区別します。

LSTMでは各時刻の「保持量＋書込量」が次のセル状態になります。GANはD更新でa,bが同じ、G更新でw,dが同じことを確認してください。「説明を次へ」は学習を実行しません。実計算は既存の実行ボタンとNotebookのセル実行で確認します。Python／Notebookの固定データ・学習条件・基準結果は変更していません。
