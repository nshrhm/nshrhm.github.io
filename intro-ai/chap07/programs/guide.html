第9回 進化的計算：Python・Notebook解説

学習目標と入口

GAの個体、ACOの経路、人工魚群の位置を評価し、更新前後を説明します。第8回までの「固定した入力で実行→結果を比較」を使います。難しいライブラリの操作は必要ありません。

スライド ／ 操作教材 ／ 操作マニュアル

Python ／ Notebook ／ Notebook環境の依存一覧

保存・環境・全セル実行

  1. ZIPを保存して新しいフォルダーへ展開します。Python、Notebook、requirements.txt、このguide.htmlが入っています。元のZIPを残してください。
  2. 既存の学習用venvを有効化します。ターミナルで python --version と python -c "import sys; print(sys.executable)" を確認します。Python 3.10以降を使えます。制作者のPython 3.14に合わせる必要はありません。
  3. VS CodeでNotebookを開き、右上のカーネル選択で同じvenvを選びます。カーネル再起動→全セル実行を行います。Notebookは同梱Pythonをimportせず、単体で動きます。
  4. 基準の3値と6変更例の出力が出れば実行完了です。予想・観察・説明を記入します。

Python単体の計算は標準ライブラリのみです。Notebook環境が未導入の場合だけ、有効化したvenvで以下を実行します。初回の環境準備にはネット接続が必要です。

python -m pip install --require-hashes -r requirements.txt

既存venvがなければ python -m venv .venv で作成します。WSL/Linuxでは source .venv/bin/activate、Windows PowerShellでは .venv\Scripts\Activate.ps1 で有効化します。VS CodeのPythonインタープリターとNotebookのカーネル選択は別なので両方を確認します。

Python版を実行する

展開先のフォルダーで実行します。

python evolutionary_computation.py --demo
python evolutionary_computation.py --demo --json

通常実行は三つの基準値と読み方、--json は照合用の詳細を表示します。uvを利用する場合は uv run --no-project python evolutionary_computation.py --demo でも実行できます。uvは受講者の必須条件ではありません。

入力は全て本教材用に作成した人工データです。外部データの取得や送信は行いません。乱数シードは65535、各手法で初期化し、20世代／反復を計算します。

GAの初期集団は100000・110000・111000・101010・010101・001111。人工魚群の初期位置は(-1.5,-1),(-1,1),(0.5,1.5),(1.5,0.5),(1,-1.5),(-0.5,-0.5)です。

ACOは完成した経路から選ぶ簡略モデルです。人工魚群の匹数による混雑上限、候補の選択、一歩の決め方は教材用であり、原著の完全再現ではありません。追尾と群れ形成を比較し、使えなければ採餌を3回まで試し、それでも見つからなければランダム移動します。全魚は更新前の同じ位置を参照します。保存した過去最良位置は表示用です。

内部の数値は絶対・相対許容誤差1e-9、表示・基準JSONは6桁で比較します。整数・ビット列・選択番号は完全一致です。20回停止は最適性の証明ではありません。

コピーで一つ変更する6実験

元のNotebookを残して別名で保存します。baseline_result と元の入力定数を変更せず、trial_ で始まる変数に結果を保存します。Pythonだけで試す場合は、別名コピーで末尾の実行部より前に該当コードを追記して実行できます。

1 ビット列を変える

問い・予想：先頭を111111にすると、その選択確率はどうなる？ 実行前に一文で予想します。

手順：Notebookの該当セルを実行します。

trial_population = list(POPULATION)
trial_population[0] = '111111'
trial_selection = ga_evaluate(trial_population)
print('先頭の選択確率:', baseline_result['ga_initial']['probabilities'][0], '→', trial_selection['probabilities'][0])

想定結果・説明する問い：1/16から6/21へ増えます。他の個体の確率も分母の変化により変わります。

リセット：この実験のセルを元の内容に戻し、カーネル再起動→全セル実行します。

元に戻す・困ったとき

  • NameError：先に定義するセルを飛ばしています。カーネル再起動後、上から全セル実行します。
  • ValueError：反復0〜200、変異率・蒸発率0〜1、視野0〜4、移動幅0〜1を確認します。GA個体は6ビット、座標は各−2〜2です。
  • カーネルが見つからない：選択したvenvにJupyter環境があるか確認します。環境の導入先とカーネルをそろえます。
  • ファイルがない：ZIPを先に展開し、ターミナルの作業フォルダーを確認します。Notebook単体の計算は同梱Pythonなしで動きます。
  • 基準値が異なる：入力・シード・反復数を確認します。再起動は編集したソースを元に戻す操作ではありません。元のZIPを別のフォルダーへ展開して再開します。
  • インストールに失敗する：既存の授業用venvに戻り、Pythonの版とネット接続を確認します。システムPythonへ直接追加しないでください。

予想と結果の差を、更新規則から説明してください。追加の提出期限・採点条件はこの教材では設定しません。
