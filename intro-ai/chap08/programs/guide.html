開始・保存・実行

  1. ZIPを保存して展開し、このguide.htmlとPython・Notebookが同じフォルダーにあることを確認します。単独実行の手順はこの文書だけで完結します。
  2. VS Codeで展開先を開き、既存の授業用venvを有効にします。Windows PowerShellなら .venv\Scripts\Activate.ps1、Linux／macOSなら source .venv/bin/activate。venvが別のフォルダーならその場所を指定してください。
  3. ターミナルで python --version を確認します。Python 3.10以降に対応します。制作側と同じバージョンを新しく要求するものではありません。
  4. python natural_language_processing.py --demo を実行します。照合用の一行表示は python natural_language_processing.py --demo --json。uvを使う環境では uv run python natural_language_processing.py --demo も使えます。
  5. Notebookは右上のカーネル選択で同じvenvのPythonを選び、カーネルを再起動して「すべて実行」します。同梱Pythonのimportは不要です。

Python単体なら追加インストールは不要。Notebookのカーネル等がない場合だけ、有効なvenv内で python -m pip install -r requirements.txt を実行します。この準備には通信が必要です。用意済み環境での計算はオフラインで行えます。システム全体へインストールしないでください。

出力を読む

  • morph：候補の開始・終了位置、品詞、コスト、採用した分割。
  • bigram：語彙、回数、分母、確率。語彙の順は猫・が・眠る・犬・走る・文末です。
  • tfidf：各文書のTFと、文書集合全体のDF・IDF・TF-IDF。
  • vectors／similarity：観測した共起回数と類似度。学習したベクトルではありません。
  • first_update：猫→がの初期確率・損失・勾配。training：20エポック後の入力・出力ベクトルと、全16組の平均損失履歴。
  • speech：人工値による順位スコアと選択候補。実音声の認識精度ではありません。

成功の目印：研究／生活の合計2、がの次の眠るは0.3、先頭文書の猫のTF-IDFは0.231049、猫・犬の共起類似度は1、λ＝1の候補は飴・λ＝0なら雨。実装のJSONは小数点以下6桁です。数値表の全文はNotebookの基準セルに残します。

学習計算の詳しい読み方

中心語の入力ベクトルをv、候補jの出力ベクトルをu[j]とします。内積をsoftmaxに通した確率p[j]と、正解だけ1のy[j]の差をe[j]とすると、入力側の勾配はΣ e[j]u[j]、出力側はe[j]vです。全て更新前の値で計算し、各ベクトルから学習率×勾配を引きます。

実装は最大内積を引いたsoftmaxとlog-sum-expによる損失を使います。一つの組の損失と、全16組の平均損失を区別します。グラフは平均損失、候補別の表は猫→がの確率です。0〜200エポックの範囲で、文・中心位置・周辺位置の順序を固定します。学習の成功や日本語全体の意味関係の再現を保証しません。

リセットとエラー対処

  • NameError：途中から実行せず、カーネルを再起動して全セル実行します。
  • カーネルがない・ModuleNotFoundError：Pythonの実行環境とカーネルが一致するか確認し、必要なら上記requirementsをvenvに入れます。演習Python自体には外部依存がありません。
  • ファイルがない：ZIPを展開したフォルダーで実行し、拡張子が.py.txtなどになっていないか確認します。
  • ValueError：辞書コスト0〜20、α0〜5、窓幅1〜3、学習率0〜1、エポック整数0〜200、λ0〜3。コーパスは1〜20文、各1〜20語。空文書・NaN・語彙外の文脈は受け付けません。
  • コサイン類似度のNone：ゼロベクトルのため未定義です。エラーを隠して0へ置き換えないでください。
  • 音響尤度・事前確率は正の値。事前確率の合計は1です。画面の入力では雨側を指定し、飴側は1からの差とします。
  • 数値が違う：入力・シード・処理順・パラメーターを戻して再実行します。関数内の基準定数を変更せず、別変数で実験してください。

この教材は小規模な計算モデルです。実用解析器の辞書・品詞体系や音声モデルの出力と同じ結果を要求しません。

段階表示とコードを対応させる

操作教材の「計算の内訳・確かめること」を開き、入力と同じ順序で途中の値を比較します。説明の前後移動では計算は進みません。プログラム側では同じ固定入力と条件でセルを実行し、表示の丸めによる末尾の差と、計算条件の違いを区別してください。

辞書分割は文字境界と経路コスト、bigramは文末を含む候補数、TF-IDFはTFとDFの分母を確認します。Skip-gramの現在値は既存更新処理から表示に渡し、説明用の別の学習計算は追加していません。

Python／Notebookの計算コード・固定データ・期待値は変更していません。変更実験は元データのコピーで行い、再実行前には説明済みの初期化手順を使います。
