第11回 画像認識：プログラムの保存と学び方

到達目標と開始方法

画素から特徴量を計算し、テンプレートの照合位置と限界を数値で説明します。前提は二重リスト・繰り返し・平均・第7回の積和です。演習の計算部分はPython標準ライブラリのみ。画像ライブラリや学習フレームワークは追加しません。全て自作の人工入力で、乱数を使いません。

スライド ／ 操作教材 ／ 操作マニュアル

Pythonを保存 ／ Notebookを保存 ／ 一式ZIPを保存

保存と実行

  1. ZIPを保存して展開し、同梱のguide.htmlをブラウザーで開きます。ZIP内だけで以下を開始できます。
  2. VS Codeで展開先を開きます。既存のvenvを有効にし、そのPythonインタープリターを選びます。Python 3.10以上を使用し、制作側の版を新しく導入する必要はありません。
  3. ターミナルでファイルを置いた場所へ移動し、次を実行します。
python image_recognition.py --demo

uvを既に使っている場合はuv run python image_recognition.py --demoでも実行できます。Notebookの実行には既存のJupyter環境を使用します。必要な環境を再作成する場合のみ、venv内でpython -m pip install -r requirements.txtを実行します。システム全体へのインストールは不要です。

Notebookで全セル実行

Notebookを保存し、右上のカーネル選択から既存venvを指定します。「カーネルを再起動」→「すべて実行」を選び、最後の「基準入力・結果を保持しました」を確認します。同梱.pyをimportせず、Notebook内の定義だけで動きます。途中セルだけを実行すると未定義の関数や古い値が残る場合があります。

基準結果と出力の読み方

  • binary：しきい値1、前景9画素。features：面積9・重心[2,2]。
  • mean[1][1]：2.777778（計算は25/9）。median[1][1]：2。
  • laplacian[1][1]：−28。負の応答は消さず、表示と計算を分けます。
  • pool：[[6,8],[14,16]]。これは別入力1〜16の4×4から計算。
  • ssd.best：行1・列2・値0。zncc.best：同じ位置・値1。
  • brightness_pair：同じ形に10加算した比較はSSD400・ZNCC1。
  • constant_zncc：None／JSONではnull。一定値の領域は分母0なので未定義です。

座標は0始まりの行・列。SSDは小さい方、ZNCCは大きい方を選びます。validで画像内だけを比較し、同点は全候補を示した上で行・列順の先頭を表示します。最良候補があることは物体存在の証明ではありません。

変更実験

元の.pyとNotebookをコピーし、基準結果baseline_resultを保持します。以下はNotebookの定義・基準セルより後で実行します。Python版ではコピーしたファイルでmain()より前へ同じコードを置くこともできます。6件とも入力のコピーを用い、元の定数は書き換えません。

二値化のしきい値

問い：t=2で前景は何画素か。

予想：1のままか、減るかを予想する。

手順：次を実行し、基準と比較します。

trial_threshold = binary(deepcopy(IMAGE), 2)
print(features(trial_threshold))

想定結果：前景1画素、重心(2,2)。

説明する問い：画素値2が前景に入らない理由を説明する。

孤立画素の変更

問い：中心9を2へ戻すと平均と中央値はどうなるか。

予想：どちらが大きく変わるかを予想する。

手順：次を実行し、基準と比較します。

trial_image = deepcopy(IMAGE)
trial_image[2][2] = 2
trial_smooth = filtering(trial_image)
print(trial_smooth[1][1], filtering(trial_image, "median")[1][1])

想定結果：平均2、中央値2。基準の平均は25/9。

説明する問い：出力の中心以外も変わる理由を説明する。

明暗反転と符号

問い：9−画素値の画像ではラプラシアンの中心はどうなるか。

予想：符号と大きさを予想する。

手順：次を実行し、基準と比較します。

trial_inverse = [[9-x for x in row] for row in IMAGE]
trial_edges = filtering(trial_inverse, "laplacian")
print(trial_edges[1][1])

想定結果：−28から+28。

説明する問い：絶対値だけを見ると何が区別できなくなるか。

空の領域

問い：しきい値9で重心はどう表示されるか。

予想：(0,0)と未定義のどちらかを理由付きで予想する。

手順：次を実行し、基準と比較します。

trial_features = features(binary(deepcopy(IMAGE), 9))
print(trial_features)

想定結果：面積0、重心None（未定義）。

説明する問い：空の領域を左上の物体と区別する理由は何か。

テンプレートの回転

問い：90度回転後、元の位置のSSDは0か。

予想：回転前後の画素対応を書いて予想する。

手順：次を実行し、基準と比較します。

trial_template = rotate(deepcopy(TEMPLATE))
trial_rotation = score(window(SCENE, 1, 2, 2, 2), trial_template)
print(trial_template, trial_rotation)
print(match(SCENE, trial_template))

想定結果：回転後[[3,1],[4,2]]、元の位置のSSD=10。最良位置も全探索で確認する。

説明する問い：同じ形でも画素の対応が変わることを説明する。

明るさの変更

問い：探索画像へ10を加えると最良位置はどうなるか。

予想：SSDとZNCCで同じ結果になるかを予想する。

手順：次を実行し、基準と比較します。

trial_bright = tone(deepcopy(SCENE), 10)
trial_ssd = match(trial_bright, TEMPLATE)
trial_zncc = match(trial_bright, TEMPLATE, "zncc")
print(trial_ssd["best"], trial_zncc["best"])
print(score(window(trial_bright, 1, 2, 2, 2), TEMPLATE))

想定結果：元の位置のSSD=400。ZNCCは1で最良(1,2)。SSDは別の位置を選ぶ。

説明する問い：平均を引く操作の効果と、回転には対応しない理由を説明する。

リセットとエラー対処

元ファイルを再度コピーし、Notebookのカーネルを再起動して全セル実行します。FileNotFoundErrorやファイルが見つからない表示は展開先・カレントディレクトリーを確認。NameErrorは上から実行。カーネルが選べない場合は既存venvにipykernelがあるか確認します。

ValueErrorは不正入力を表します。空・不揃いの行列、NaN・無限大、16×16超、画像より大きいテンプレート、奇数サイズの2×2プーリングを受け付けません。Noneは有効な計算上の未定義で、エラーとは異なります。基準値が違うときは行・列、入力、フィルタの種類、セル順を確認してください。

比較の精度と限界

実数は計算途中で丸めず、JSON基準値は小数点以下6桁です。表示桁の差は元の値で確認します。制作側の数値検査は絶対・相対許容誤差1e-9。実写真の認識率や本人照合、提出・採点の検査ではありません。未確認の公開URLを開始条件にはしません。
