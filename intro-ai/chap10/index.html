到達目標：Q学習の一回の更新を計算し、探索と評価の違いを説明する。

小さな分岐環境で、行動の選択と価値の更新を追います。 実機の性能や一般的な学習成功を測る授業ではありません。

  2. 操作教材で計算過程を確かめる。
  3. Python／Notebookで同じ結果を再現する。
  4. コピー上で一項目変え、理由を説明する。

エージェントとは

環境から情報を受け取り、環境へ働きかける主体。

観測 → エージェント → 行動 → 環境 → 次の観測

この循環を、ソフトウェアでもロボットでも考えられる。

観測はエージェントが受け取れる情報です。 現実では環境の全状態が分かるとは限りません。

エージェントと学習は別の概念

決められた規則で動くエージェントもある。

学習する場合：経験を使い、内部の値や規則を変える。

今回：Q表を更新し、その値を行動選択に使う。

エージェントの定義に学習機能を必須としません。 学習の有無と、環境と相互作用することを分けて説明してください。

観測・行動・環境

観測：今どこにいるか。

行動：左へ進む／右へ進む。

環境：次の状態と報酬を返す規則。

今回は状態番号を完全に観測できると仮定する。

部分的な観測では記憶や推定が必要になる場合があります。 この教材ではその難しさを除き、更新計算へ集中します。

ソフトウェアとロボット

ソフトウェア：画面やデータを観測し、選択や提案を行う。

ロボット：センサーで観測し、モーター等で働きかける。

同じ循環でも、観測・行動・制約は異なる。

ロボットには物理的な制約があります。 分岐図で動くことを、そのまま実機制御の検証と考えないでください。

関連するモデルの位置づけ

セル・オートマトン：局所規則でセルの状態を更新。

交通流：車両と道路の相互作用をモデル化。

ロボティクス：身体を持つシステムの観測と制御。

これらに強化学習が必須とは限らない。

モデルや応用分野の例として紹介します。 今回は専用の交通流やロボット演習を追加せず、分岐環境を扱います。

今回の分岐環境

状態0から開始。行動は左・右。

状態 左：次状態／報酬 右：次状態／報酬
0 1・終端／4 2／0
2 3・終端／0 4・終端／10

1・3・4は終端。1エピソードは最大2行動。

環境は決定的で、同じ状態と行動には同じ結果を返します。 この表と数値は授業用に設計したものです。

操作：エージェントと環境

予想：右を一回選ぶと、すぐ10を得られるか。

操作：右 → 右の順に進む。

説明：報酬を受け取る時点を区別する。

概念図：枝は行動／報酬。1・3・4は終端。

このテーマを操作する

最初の右行動は報酬ゼロです。 次の行動を選ぶ機会が残っていることが重要です。

状態・行動・報酬

状態 s：意思決定の状況。

行動 a：その状態で選べる操作。

報酬 r：一回の遷移に対して環境が返す数値。

報酬は正解の行動ラベルとは異なる。

今回の報酬は移動後に分かります。 教師あり学習のように、各状態に正解の行動を直接与える設定ではありません。

方策は行動の選び方

方策：状態から行動、または行動の確率を決める規則。

例：常に左／Q値が大きい方／時々ランダム。

Q表は価値の見積もり、方策は選択の規則。

Q表と方策は同じものではありません。 同じQ表でも探索率を変えると選択の確率が変わります。

即時報酬と報酬合計

左：報酬列 [4] → 合計4。

右→右：報酬列 [0, 10] → 合計10。

最初の報酬だけで選ぶと、後の10を考慮できない。

行動直後の報酬と、エピソード全体の報酬を分けます。 後から得る報酬をどう評価するかが次の論点です。

割引収益を計算する

2行動の割引収益：G = r₁ + γ r₂

γ=0.9：右→右は 0 + 0.9×10 = 9。

γ=0.2：右→右は 2、左は4。

報酬合計10が同じでも、割引収益は変わる。

最初の報酬には割引を掛けません。 割引率は将来の報酬を現在の選択でどれだけ重視するかを変えます。

Q値は状態と行動の価値

Q(s,a)：その行動から先の割引収益の見積もり。

Q表 左 右
状態0 0 0
状態2 0 0

初期値は全て0。終端には行動を選ぶ行を置かない。

このテーマを操作する

この表のゼロは未学習の初期値です。 環境から計算できる最適Q値を、学習時の初期値として与えてはいません。

探索と活用

活用：今のQ表で最大の行動を選ぶ。

探索：現在の評価だけに従わず、行動を試す。

未経験の行動の価値は、初期値のまま残る場合がある。

探索には良い行動を知る機会と、短期的な報酬を失う可能性があります。 常に活用すれば十分とは限りません。

ε-greedyの規則

確率ε：左右から一様に選ぶ。

確率1−ε：Q値が最大の行動を選ぶ。

探索でも最大Q値の行動が選ばれることがある。

探索は必ず悪い方を選ぶ規則ではありません。 左右二つから一様に選ぶので、最大側を選ぶ場合もあります。

操作：選択確率を比べる

Q左=0、Q右=1、ε=0.3の場合：

P(右)=0.7+0.3÷2=0.85

P(左)=0.3÷2=0.15

有限の選択列では、この比率と完全一致するとは限らない。

このテーマを操作する

理論上の確率と実際に数えた割合を分けます。 画面の選択列は固定シードの乱数で再現できるようにしています。

同点と乱数の扱い

Q値が同点なら、貪欲選択は左。

各学習行動で乱数を必ず2個使用する。

1個目：探索するか。2個目：探索時の左右。

エピソードをまたいで乱数状態を継続する。

活用する場合も二個目を消費し、実装間で順序をそろえます。 この同点処理と乱数手順は教材独自の再現性の約束です。

学習率α

α=0：経験してもQ値を変えない。

α=1：今回の目標値で置き換える。

α=0.5：旧Q値と目標値の中間に動く。

大きいほど常に良いとは限らない。

学習率は一回の更新幅を決めます。 今回の固定学習率を一般の収束条件と同一視しないでください。

割引率γと探索率ε

γ：将来の価値を目標値へ反映する強さ。

ε：ランダムな探索を行う確率。

α：目標値へ近づく更新の強さ。

三つを一度に変えず、一項目ずつ比較する。

割引率と探索率は別の役割です。 将来を重視しても、その行動を経験するとは限りません。

Q学習の更新式

Q ← Q + α ×（目標値 − Q）

非終端：目標値 = r + γ max Q(s′,a′)

終端：目標値 = r

経験した状態・行動の要素だけを更新する。

次状態の最大Q値を使いますが、その次の行動を実際に選んでから計算する規則ではありません。 更新されるのは今回選んだ要素です。

誤差と更新後の値

旧Q=2、報酬=1、次の最大Q=6。

α=0.5、γ=0.9、非終端なら：

目標値=1+0.9×6=6.4

誤差=6.4−2=4.4 → 新Q=2+0.5×4.4=4.2

計算の順序を目標値、誤差、新しい値に分けます。 この一回更新の数値例は、分岐環境とは別の練習入力です。

終端には将来の行動がない

旧Q=0、報酬=10、α=0.5。

終端なので目標値=10。

新Q=0+0.5×(10−0)=5。

次の最大Qを入力しても、終端では使わない。

終端からさらに価値を足すと、存在しない将来の行動を数えてしまいます。 終端かどうかを明示して計算します。

操作：一回の更新を追う

予想：旧Q=6、報酬0、終端なら変化するか。

α=0.5 → 目標値0 → 新Q=3。

報酬0でも更新する。小数を整数へ切り捨てない。

このテーマを操作する

報酬ゼロは更新を省く条件ではありません。 目標値と旧Q値が異なれば、ゼロ報酬でも値が変わります。

一回目の右→右

初期Qは全て0、α=0.5、γ=0.9。

0→2：次の最大Qは0 → Q(0,右)=0。

2→4：終端報酬10 → Q(2,右)=5。

先の状態が更新されても、過去の要素は自動では変わらない。

二つの更新は実際の行動順に行います。 最後に得た報酬が一度で全ての過去状態に戻るわけではありません。

二回目の右→右

0→2：目標値=0+0.9×5=4.5。

Q(0,右)=0+0.5×4.5=2.25。

2→4：Q(2,右)=5+0.5×(10−5)=7.5。

遅れた報酬が、再び経験することで前の状態へ伝わる。

最初の更新では、その時点の次状態の値である五を使います。 後で得られる七点五を先取りしてはいけません。

負の報酬も更新できる

旧Q=2、終端報酬−4、α=0.5。

目標値−4 → 新Q=2+0.5×(−4−2)=−1。

報酬の符号で更新を省かない。

負の報酬は避けたい結果を表す設計にも使えます。 今回の変更可能範囲はマイナス百から百です。

既知環境から計算した参照値

γ=0.9の最適Q値：

状態 左 右
0 4 9
2 0 10

これは環境表から求めた参照値。学習処理には入力しない。

参照値と有限回の学習結果を分けます。 表示で九に丸められていても、計算値が厳密に九へ到達したとは限りません。

操作：エピソードを重ねる

基準：α=0.5、γ=0.9、ε=0.3。

100エピソード、シード65535。

1行動 → 1エピソード → 残り全部の順に観察。

Q表・更新履歴・終了回数を対応させる。

このテーマを操作する

一エピソードボタンは途中なら現在のエピソードを最後まで進めます。 条件を書き換えると初期Q表とシードからやり直します。

学習後の評価

学習済みQ表を固定する。

探索なし、更新なし、乱数消費なし。

状態0から貪欲方策で進み、経路・報酬合計・割引収益を記録。

学習中に偶然選んだ経路と、評価方策の経路は異なる場合があります。 評価を繰り返しても学習状態は変わりません。

基準結果の読み方

Q表（小数点以下6桁で丸め）：

状態0：[3.999998, 9.000000]

状態2：[0.000000, 10.000000]

評価：0→2→4、報酬合計10、割引収益9。

これは指定した条件と乱数列で確認する基準です。 別のシードや有限の試行で、同じ結果になるという保証ではありません。

条件を変えたら学び直す

初期Q表は0、乱数は指定シードに戻す。

基準の設定をコピーして一項目だけ変更。

途中のQ表へ別条件の経験を継ぎ足さない。

例：γ=0.2なら、参照Q(0,右)=2。

割引率を変えると、評価したい価値そのものが変わります。 条件比較では初期条件をそろえます。

操作：基準と変更を比較

ε=0：初期同点で左を選び、その報酬4を学ぶ。

右の価値を知らないまま終える場合がある。

γ=0.2：将来の10より即時の4を重視する設定。

同じ経路でも、選ばれた理由は同じとは限らない。

このテーマを操作する

探索を止めた場合と、価値の定義を変えた場合を比べます。 経路だけでなくQ表と設定も読む必要があります。

ばらつきと限界

有限回で最適方策が得られるとは限らない。

毎回の報酬やQ値が必ず増えるわけではない。

固定学習率・有限試行の結果を一般の収束保証にしない。

完全観測・決定的・小規模という仮定がある。

この教材で動作したことと、現実の複雑な環境への有効性を区別します。 シードを変えることはばらつきの確認の入口です。
