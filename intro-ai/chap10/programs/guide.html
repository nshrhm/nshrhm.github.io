第12回 エージェントと強化学習：プログラムの保存と学び方

目標と開始方法

Q表の一回更新を計算し、探索中の行動と固定方策の評価を区別します。前提はリスト、辞書、繰り返しと四則演算です。小さな分岐環境を使い、実行部分はPython標準ライブラリのみです。

スライド ／ 操作教材 ／ 操作マニュアル

Pythonを保存 ／ Notebookを保存 ／ 一式ZIPを保存

保存して実行する

  1. ZIPを保存・展開し、同梱guide.htmlを開きます。以下は同梱ファイルだけで開始できます。
  2. VS Codeで展開先を開き、既存venvを有効化し、そのPythonインタープリターを選びます。Python 3.10以上が対象で、制作環境のPython版の導入は不要です。
  3. 展開先のターミナルで実行します。
python agent_qlearning.py --demo

uvを既に使っていれば uv run python agent_qlearning.py --demo も使えます。Notebookは既存Jupyter環境で開きます。環境再作成が必要なときだけ、venv内で python -m pip install -r requirements.txt を実行します。システム全体へのインストールは不要です。

Notebookのカーネルを既存venvへ切り替え、「カーネルを再起動」→「すべて実行」を選びます。最後の「基準入力・結果を保持しました」が成功の目印です。同梱Pythonをimportせず、Notebook内の定義で動作します。

環境と出力の読み方

開始0、非終端0・2、終端1・3・4。0左→1で4、0右→2で0、2左→3で0、2右→4で10。各エピソードは最大2行動です。Q表の行は状態0・2、列は左・右です。

基準はα=0.5、γ=0.9、ε=0.3、100回、シード65535、遅延報酬10。各学習行動で32ビットLCGを2回進め、探索判定と左右選択に使います。探索しなくても2個消費します。貪欲選択の同点は左です。

  • baseline：基準設定・Q表・学習回数・乱数状態・評価。
  • first_updates：最初の6行動。state/action、old、target、error、newを読む。
  • optimal_reference：環境から計算した最適Q値。学習に入力しない。
  • changes：コピーから開始した6変更結果。
  • evaluation.path：評価経路、sum：報酬合計、discounted：割引収益。

基準Q表は6桁丸めで[[3.999998,9],[0,10]]。評価経路は[0,2,4]、合計10、割引収益9。これは指定条件の結果であり、有限回の成功保証ではありません。内部計算は丸めず、整数への切り捨ても行いません。評価は探索・更新・乱数消費を行いません。

関数を読み解く

transitionは環境表、select_actionはε-greedy、learnは一要素の更新です。Trainer.step()は1行動、episode()は現在の回の終了まで、finish()は残り全部を実行します。train(config)は毎回新しいQ表と乱数から開始します。historyには全更新が残ります。

一回更新は旧Q＋α×(目標値−旧Q)。非終端の目標値は報酬＋γ×次の最大Q、終端では報酬だけです。報酬0でも更新します。右→右を2回経験すると、状態2右は5→7.5、状態0右は0→2.25になります。

確認とエラー対処

baseline_result == demo() と baseline_run == train(baseline_config) がTrueなら基準は保持されています。結果が違ったら保存した元ファイルへ戻し、カーネル再起動後に全セル実行してください。NameErrorは途中セルだけ実行していないかを確認します。ValueErrorは空欄・NaN・範囲外・非整数を見直します。

α・γ・εは0〜1、回数は整数0〜200、遅延報酬は−100〜100、シードは整数0〜4294967295です。状態や行動は環境表の値を使い、終端から行動しません。ModuleNotFoundErrorでJupyter関連が不足するときは、選択したvenvとカーネルを確認します。Python単体演習には追加パッケージは不要です。

出力を保存する場合は新しいoutputsフォルダーを作り、元ファイルと分けます。探索を変えても毎回の報酬が必ず改善するとは限りません。評価で得た経路は、この決定的な小環境と指定Q表に対する結果です。
