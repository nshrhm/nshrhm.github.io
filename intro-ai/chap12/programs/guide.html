第14回 人工知能の今後の動向：プログラムの保存と学び方

目標と保存・実行

固定結果の集計、利用比率による推定、回答保留と費用を比較します。前提はリスト・辞書・関数と割合。学習・生成・モデル取得・乱数・APIは使いません。

スライド ／ 操作教材 ／ 操作マニュアル

Pythonを保存 ／ Notebookを保存 ／ 一式ZIPを保存

  1. ZIPを保存・展開し、同梱guide.htmlを開きます。以下は同梱ファイルだけで実行手順をたどれます。
  2. VS Codeで展開先を開き、既存venvを有効化してPythonインタープリターを選びます。Python 3.10以上を使います。制作環境の版そのものを要求しません。
  3. ターミナルで python ai_evaluation.py --demo を実行します。JSONだけ保存する場合は python ai_evaluation.py --demo --json > result.json。uv既習なら uv run python ai_evaluation.py --demo でも実行できます。
  4. Notebookは既存のJupyter環境で開き、同じvenvのカーネルを選択。「カーネルを再起動」→「すべて実行」を選びます。カーネルがない場合だけvenv内で python -m pip install -r requirements.txt を実行し、再選択します。依存の初回取得にはネット接続が必要です。システム全体へは入れません。

成功の目印はA7/12・B8/12、選択A・しきい値80・費用32、末尾の「基準入力・結果を保持しました」。Notebookは同梱Pythonをimportしません。Python版の実行部分は標準ライブラリだけです。

入力と出力の読み方

正誤とスコアはDATAに固定してあります。N1〜N6が通常条件、C1〜C6が条件変化。スコアは確率ではなく、実AIから取得した結果でもありません。BASEはしきい値0、通常条件50%、確認費用4、A単価1、B単価3、必要正答率80%、必要回答率50%です。

evaluate(config)で一つの条件を評価します。groupsは各条件と全体の固定集計、mixtureは利用比率による推定、answersは指定しきい値での回答・保留・費用、candidatesは固定6候補、bestは要件を満たす最小費用の候補です。推定比率は固定候補の選択へ混ぜません。

correctは元の正解数、correct_answeredは回答した正解数、answeredは回答数、withheldは保留数。accuracyは回答中の正答率、coverageは回答率、correct_per_totalは回答した正解数/全件数です。分母の違いを確認してください。全件保留時のaccuracyはNone/JSONのnullで、0や1ではありません。

records・inspect_caseはケースを読み、aggregateはしきい値以上のケースを集計します。chooseは6候補から費用、回答率、正答率、方式A、低いしきい値の順で選びます。該当なしはNone。demo()とbaseline_resultは基準と6変更例の比較用JSONで、実数は6桁表示。計算そのものは丸め前の値を使います。

print(observation_case)

問い：保留の多い方式は費用が低いか。予想を手元へ書いてから、基準結果の対応する項目を見ます。しきい値80を保ち、確認費用4→10を試す。リセット後、Bの費用3→1だけを試す。 操作画面と同じ変更を次のNotebookのコピー上で試せます。想定結果：基準32・64、確認費用10なら62・106。B単価1ならB40。確認後の正答率は未計算。 説明する問い：総費用のどの項が変わったか。人の確認で必ず正解になるといえるか。 復帰は基準セルからの再実行です。

復帰とエラー対処

結果が違う場合は、前の実験の設定を持ち越していないか確認します。確認費用とB単価の例だけは、保留を観察するため基準しきい値80です。その基準から変える項目は一つだけです。

値・割合・費用には0〜100の整数を使います。文字列、空欄、小数、NaN、無限大は拒否されます。未知キーや方式でもValueErrorになります。NameErrorなら定義セルから全セル実行。ModuleNotFoundErrorでipykernel等がなければ、上のvenv・カーネル手順を確認します。ファイルが見つからない場合は展開先で実行しているか確認します。

「—／None／null」と「該当なし」は、全件保留や要件不適合の正常な結果です。保留後の人による確認の正答率は計算していません。架空費用を実料金・時間・消費電力へ換算しません。
