研究室配属について

研究室を知る・希望を決める・手続きを進める

2026年9月28日（月）16:30 ／ D棟1階 D-101教室

説明会・欠席者の確認・後日の参照に使う資料です。

下関市立大学データサイエンス学部3年生のみなさんに、研究室配属の流れを説明します。研究室の研究内容を理解したうえで希望先を選び、希望調査と選考を経て配属を決めます。 説明会の会場はD棟1階のD-101教室です。説明会は30分程度の予定ですが、このスライドには後から確認できるように補足も収めています。欠席した方も、順番に読んで必要な準備と手続きを確認してください。

配属までの全体像

  1. 9～10月：研究室を知る冊子を読む → 紹介・訪問・個別面接
  2. 10月：希望を申請する希望調査に回答 → 申請状況を確認 → 入力調整
  3. 10月30日（金）：第1回の配属発表定員超過研究室では選考・後半の個別面接
  4. 未配属の場合：第2回配属・最終調整11月24日（火）に第2回の配属発表
  5. 11月30日（月）：配属確定その後も卒業研究の履修条件を確認

出典：学生配布資料 冒頭・第4～7節

研究室選びは、冊子を読んで終わりではありません。説明を聞き、訪問や面接で研究内容と指導方針を確かめ、希望を申請します。 第1回で希望先に配属されなかった場合は、第2回の募集と選考に進み、必要に応じて最終調整を行います。配属確定は11月30日ですが、卒業研究を履修するための条件はその後も確認が必要です。

第1回配属の面接には2つの期間があります。前半は9月29日午前9時から10月21日午後1時までです。後半は10月22日から29日までで、定員を超過した研究室が対象です。 後半に加点できるのは、最終的な申請先の研究室で、前半に加点対象の個別面接を受けていない学生です。希望先が面接を実施する場合は、研究室選びのためにも、なるべく前半に面接を受けてください。

面接では、研究への関心と希望理由を伝える

  • 取り組みたい研究
  • 関心のあるテーマ

出典：学生配布資料 第3節・第4節

面接は、研究内容や指導方針を確かめるとともに、自分の希望を担当教員に伝える機会です。どんな研究に取り組みたいか、なぜその研究室を希望するかを整理しておきましょう。 面接の実施有無、評価基準、申込方法は各研究室が案内します。希望する研究室が面接を実施する場合は、その案内に従い、担当教員と日時を調整してください。

第1回：定員超過時は面接の有無で選考

第1回配属の判定に用いる合計点
＝ GPA ＋ 面接評価点（最大0.5点）
  • 第1回配属の最終的な第1希望研究室のみに加点します。
  • 面接評価点は、各研究室の評価基準に基づいて教員が付与します。
  • GPAは、3年次春学期までの全科目通算GPAです。
  • 面接を実施しない研究室は、GPAの高い順に選考します。

上限は6名ですが、第1回は5名で締め切る場合があります。5名で決定した研究室は第2回以降の対象外です。

出典：学生配布資料 第3節・第5節・参考

第1回配属で希望者が当該研究室の受入人数を超えた場合、面接を実施する研究室では、ジーピーエーに最大0.5点の面接評価点を加えた合計点で選考します。加点は入力調整締切時点の第1希望研究室のみで、第2回以降は加点しません。 使うジーピーエーは3年次春学期までの全 科目 通算の値です。面接を実施しない研究室はジーピーエーの高い順となります。上限は6名ですが、第1回は5名で募集を締め切る場合があります。第1回で5名の配属を決定した研究室は、その人数で確定し、第2回以降の配属対象としません。

面接評価点で、合計点の順序が変わることも

第1回配属で同じ研究室を希望する2人の、架空の計算例

希望者 GPA 面接評価点 合計点
学生A 2.80 0.50 3.30
学生B 3.10 0.10 3.20
  • GPAは学生Bの方が高くても、合計点は学生Aの方が高くなります。
  • 面接評価点は配属判定に影響します。
希望する研究室の面接案内を必ず確認してください。

出典：学生配布資料 第3節「加点の影響を示す計算例」

これは第1回配属を想定した、配布資料にある架空の計算例です。実際の学生の成績ではありません。学生Aは2.80に0.50を加えて3.30、学生Bは3.10に0.10を加えて3.20になります。 元のジーピーエーだけを見ると学生Bの方が高いですが、合計点では学生Aの方が高くなります。面接評価点は選考に影響するため、希望する研究室の案内を確かめてください。

第1回の面接評価点は、合計最大0.5点

1回ごとに0.5点ではありません。
2回面接を受けても、0.5点ずつ加算して1.0点にはなりません。
  • 面接を受けた全員に、一律0.5点が付くわけではありません。
  • 前半に当該研究室で加点対象の面接を受けた場合、後半の追加加点はありません。
  • 加点は第1回の最終的な第1希望のみ。第2回以降は加点しません。
  • 成績上のGPAそのものは変更しません。

出典：学生配布資料 第3節・第5節

0.5点は、面接1回あたりの上限ではなく、第1回配属で加える面接評価点全体の上限です。前半と後半を通じて合計最大0.5点で、面接回数を増やして点数を積み上げる制度ではありません。 また、点数は各研究室の評価基準に基づくため、一律に0.5点が付くわけではありません。加点は第1回配属の最終的な第1希望のみで、第2回以降は加点しません。この加点で成績上のジーピーエーは変更されません。

「第1希望」は、最後に申請している1研究室

10月21日（水）13:00の入力調整締切時点で、
第1希望として申請している研究室を使います。
  • 最初に入力した研究室という意味ではありません。
  • 各回につき申請する研究室は1つです。
  • 第2希望・第3希望をまとめて申請する方式ではありません。
  • 加点は第1回配属のみ。複数で面接を受けても、最終的な申請先の評価点のみを使います。

出典：学生配布資料 第3節・第4節

この資料でいう第1希望は、最初にフォームへ入力した研究室ではありません。入力調整を終え、10月21日午後1時の締切時点で申請している1研究室のことです。 各回で申請するのは1研究室だけで、第2希望や第3希望を同時に登録する方式ではありません。複数の研究室で面接を受けることはできますが、加点は第1回配属の最終的な申請先のものだけです。第2回以降には加点しません。

補足：GPAの計算方法

選考に用いるのは、3年次春学期までの全科目通算GPAです。

評価 得点 GP
秀 90～100点 4
優 80～89点 3
良 70～79点 2
可 60～69点 1
不可 59点以下 0
失格 ― 0
GPA ＝（GP × 当該科目の単位数）の総和 ÷ 履修単位数合計

面接評価点はGPA計算に含めず、第1回の最終的な第1希望の選考でのみ加算。第2回以降は加算せず、成績上のGPAも変更しません。

出典：学生配布資料「参考：選考に用いるGPAの計算方法」

ジーピーエーは、各科目のジーピーと単位数を掛けた値を合計し、履修単位数の合計で割って計算します。秀は4、優は3、良は2、可は1、不可と失格は0です。 選考では3年次春学期までの全科目 通算ジーピーエーを使用します。面接評価点はこの計算式には入れず、第1回配属の最終的な第1希望研究室での選考に限り加算します。第2回以降は加算しません。
