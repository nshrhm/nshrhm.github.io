# 音声ファイルの対応

全34枚（本文30・質問1・補足3）に、1対1で音声ファイルを対応させます。

`slide_01.mp3`～`slide_34.mp3` は34個すべて存在します。今回MP3は変更していません。読み上げ原稿は各スライドの複数行の `<aside class="notes">` です。

その他16枚は今回ノートを変更していません。ただし、既存音声を再生・照合したという意味ではありません。

再生成時はルートの `generate_voiceover.py` に `--input 研究室配属_20260928_詳細版/slide.md` を必ず指定し、`--start-slide` と `--end-slide` で対象を指定できます。今回実行するのは `make voiceover-dry-run VARIANT=detailed` の検証のみです。再生成・内容確認が済んだ項目は上記JSONと一覧を更新してください。

`make check-slides-audio VARIANT=detailed` はファイルの存在と構造を検証します。既存音声が最新ノートと一致することや、実際に再生できることは別途確認が必要です。

スライドを挿入・削除・並べ替えした場合、生成前に音声参照と対応表を更新してください。
