データサイエンス学部3年生のみなさんに、研究室配属の流れを説明します。研究内容を理解したうえで希望先を選び、希望調査と選考を経て配属を決めます。 説明会は9月28日月曜日の16時30分から30分程度、会場はD棟1階のD-101教室です。この資料では、当日配布資料の内容を順番に確認できます。

11月30日の配属確定までの流れ

  1. 9～10月：研究室を知る冊子 → 説明会・訪問・個別面接（実施する研究室）
  2. 10月：希望調査に回答・入力調整希望研究室と理由を整理し、期限内に申請
  3. 10月30日（金）：第1回の配属発表申請結果に基づく選考・配属
  4. 未配属の場合：第2回配属・最終調整11月24日（火）：第2回の配属発表
  5. 11月30日（月）：配属確定配属後も卒業研究の履修条件を確認

出典：当日版 冒頭・第4～7節

まず冊子を読み、紹介や訪問で研究室を知ります。面接を実施する研究室では、面接の案内も確認してください。そのうえで希望調査に回答し、必要に応じて入力を調整します。 第1回の発表は10月30日です。配属されなかった場合は第2回と最終調整に進み、11月30日に配属が確定します。履修条件の確認も必要です。

面接の実施は、研究室によって異なる

面接を実施する研究室

申込方法・評価基準を確認し、担当教員と日時を調整します。

面接を実施しない研究室

定員超過時はGPAで選考します。

実施の有無・申込方法・評価基準は、各研究室が案内します。

面接を実施する希望先では、研究室選びのためにもできるだけ早めに面接を受けましょう。

出典：当日版 第3・5節

すべての研究室が面接を行うわけではありません。まず希望先で実施するかどうかを確認してください。申込方法や評価基準も各研究室の案内に従います。 面接を実施する希望先では、研究室選びのためにもできるだけ早めに面接を受けましょう。具体的な日時は担当教員と調整します。面接を実施しない研究室では、定員超過時にジーピーエーで選考します。

出典：当日版 第3・5節・参考

面接評価点は研究室ごとの基準で評価されます。全員に一律で0.5点を加えるものではなく、面接の回数にかかわらず合計で最大0.5点です。 この点数は第1回の配属選考で、定員を超えた面接実施研究室がジーピーエーに加えて使います。成績上のジーピーエーそのものが変更されるわけではありません。

加点は、第1回の最終的な第1希望のみ

第1回配属の、入力調整締切時点の第1希望研究室のみ
10月21日（水）13:00時点で最終的に申請している研究室の評価点を使います。
  • 複数の研究室で面接を受けることはできます。
  • 他の研究室の評価点を引き継ぐ・合算することはできません。
  • 希望先を変更した場合も、変更前の研究室の点数は引き継ぎません。
第2回以降の配属では、面接評価点を加算しません。

出典：当日版 第3～4節

加点するのは、第1回配属の入力調整締切時点で最終的に申請している第1希望研究室の評価点だけです。締切は10月21日水曜日の13時です。 複数の研究室で面接を受けることはできますが、他の研究室の点数を引き継いだり合算したりはできません。希望先を変えた場合も同じです。第2回以降の配属には面接評価点を加算しません。

2027年度の履修には、3条件すべてが必要

配属が確定しても、卒業研究の履修には以下をすべて満たす必要があります。

  1. 在学期間が3年間以上であること。
  2. 修得単位数（自由科目を除く）の合計が80単位以上であること。
  3. DSプロジェクトの単位を修得していること。
修得単位数とDSプロジェクトは、2027年3月の成績公表で確認。
条件を満たさない学生は、2027年度は研究室に所属できません。

配布資料に記載されたデータサイエンス学部履修規程第11条の条件。

出典：当日版 第7節

配属が確定しても、卒業研究の履修には3つの条件すべてが必要です。在学期間が3年以上、自由科目を除く修得単位数が80単位以上、そしてディーエスプロジェクトの単位を修得していることです。 特に修得単位数とディーエスプロジェクトは、2027年3月の成績公表で確認されます。条件を満たさない場合、2027年度は研究室に所属できません。配属手続きとあわせて単位修得にも注意してください。

出典：当日版 参考「選考に用いるGPAの計算方法」

評価をジーピーに置き換えると、秀は4、優は3、良は2、可は1、不可と失格は0です。選考に使うのは3年次春学期までの全科目 通算のジーピーエーです。 科目ごとのジーピーにその科目の単位数を掛け、それらを合計して履修単位数合計で割ります。面接評価点はこの計算には含めず、対象の配属選考で加算します。成績上の値が変わるわけではありません。

これから行うことを確認する

  • 冊子を読み、複数の研究室を比較。質問・希望理由を整理する。
  • 紹介・訪問の案内を確認。希望先が面接を実施する場合は早めに相談。
  • 10月16日（金）17:00までに第1回の希望調査に回答する。
  • 申請状況を確認し、10月21日（水）13:00までに希望先を確定する。
  • 配属結果と学部の最新案内を確認。未配属なら第2回・最終調整へ。
  • 2027年3月の成績公表で、卒業研究の履修条件を確認する。

出典：当日版 第1～7節
