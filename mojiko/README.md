# 門司港レトロ旅のしおり PWA

2026年11月13日（金）、小倉南区葉山町08:00頃発・16:00頃帰着の夫婦日帰りドライブ用しおりです。[Issue #85](https://github.com/nshrhm/nshrhm.github.io/issues/85)に対応しています。

## 旅程

- 推奨A：船なし。08:45頃駐車、港・駅の朝散歩、休憩、11:00跳ね橋、11:25頃焼きカレー、12:35頃プリン、13:10頃建築散策、14:25頃買物・休憩、15:10頃現地発。
- 橋は駅・海峡プラザ側から鑑賞。11:10〜11:15頃に移動開始なら昼食11:25頃、11:20の閉橋まで見るなら昼食を11:35頃へ変更。
- B：巌流島を希望する場合の唐戸経由候補。門司港09:30→唐戸09:35頃、唐戸10:25→巌流島10:35頃、巌流島11:30→唐戸11:40頃、唐戸12:00→門司港12:05頃。
- Bでは11:00の橋を14:00へ変更、昼食12:15・プリン13:20へ移し、建築の館内巡りを省略。船は2航路・4回乗船。当日の運航と帰りの便を確認できなければAへ。
- 徒歩はAで全体3〜4km程度、Bで島内込み4〜5km程度の概算。車の45分／50分、徒歩各区間の所要は計画上の見積りで、実測・到着保証ではありません。
- 雨天は九州鉄道記念館やレトロ建築1館と休憩へ置換。臨時休館・臨時休業は当日確認。
- イルミネーション等の別日イベントは予定から除外。旧門司三井倶楽部は飲食店営業終了の公式告知を受け、食事候補から削除しました。

### Bの時間計算と限界

- 往路乗換：10:25 − (09:30 + 5分) = 50分。下船・切符・乗船列に10〜15分を見込み、10:15までに乗船待ち。
- 島滞在：11:30 − (10:25 + 10分) = 55分。11:20までに桟橋へ戻るため、散策45分以内。
- 復路乗換：12:00 − (11:30 + 10分) = 20分。下船・乗り場確認に10分、11:50頃から乗船待ち。
- 門司港帰着後：15:10 − (12:00 + 5分) = 185分。昼食・プリン・14:00の橋に絞り、館内巡りを省略。
- 11:30の帰り便を逃した場合の掲載ダイヤ候補は巌流島12:10→唐戸12:20頃→唐戸12:40→門司港12:45頃。昼食13:00頃、橋・建築を省く。欠航時に次便が動くと推定しない。
- 交通・風・混雑・切符購入・乗下船の所要は当日次第。徒歩時間は地理を踏まえた余裕込みの計画値で現地実測ではありません。

## 実装

ビルド不要の静的HTML/CSS/JS。新しい実行時依存はありません。

- `index.html` は常に推奨A。`plans.html` はA/B/雨天の切替と保存。
- `map.html` は徒歩区間を分割（Googleマップ経由地は最大3地点）。海を徒歩で渡る経路は作らず、船の時刻は公式へリンク。
- `restaurants.html`、`links.html`、`story.html`、`offline.html`、manifest・共有・カレンダーも更新。
- localStorageは `mojiko:2026-11-13:v1:` 以下に保存。以前の汎用キーは読み込まず、削除もしません。
- 「次の予定」は日本時間で判定。表示中のプランの未完了項目だけを対象に、30秒ごと・チェック変更時・タブ復帰時に更新。終了後は朝へ戻しません。
- SWキャッシュは `mojiko-ganryujima-shiori-2026-11-13-v1`。同接頭辞の古いキャッシュだけ削除。旧アプリは更新UIがないため、新SWの有効化時に旧版の開いているページを1回再読込します。他アプリのキャッシュは保持。
- HTMLはnetwork-first、同一スコープのアセットはcache-first。manifest・ICSも事前保存。外部写真・地図・最新の運航や天気はオンラインが必要。
- ICSは日本時間11/13 08:00〜16:00をUTCで記録、CRLFとUTF-8を壊さない75オクテット折返し。推奨Aの1予定のみ。

## ローカル確認

```sh
make serve
# http://127.0.0.1:8000/mojiko/
make check
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
CHROMIUM_EXECUTABLE=/absolute/path/to/chrome \
make check-browser
```

`playwright` と対応Chromiumが既存環境で解決できれば、環境変数は不要です。テスト目的の依存を本アプリへ追加していません。ブラウザ検証は自身のループバックHTTPサーバーを起動・終了し、結果と画面を `/tmp/mojiko-verification/` へ保存します。外部リソースは遮断し、外部サイトの情報照合と分離しています。

`make check` は日付・曜日・旧案内の残存、メタ情報、ローカルリンク、徒歩URL、A/B時刻順、トップとAの一致、船の時間計算、ICS・manifest・キャッシュ対象を検査します。`make check-browser` はチェック保存と旧キー分離、プラン切替、日本時間の時刻表示、共有・インストールイベント、スマホ幅、オフライン、保存拒否時、旧SWからの更新を検査します。

`tools/fixtures/legacy-worker.js` は更新検証専用に保存した旧v2の実際のSWです。本番のAPP_SHELLには含めません。テストは旧SW＋最小の旧画面からの更新を再現します。
