## 実装

ビルド不要の静的HTML/CSS/JS。新しい実行時依存はありません。

- トップと旅程ページのメインを統一。切替は「メイン旅程／遅延時の後続便／雨・欠航時の判断」。
- 地図は駐車場・各桟橋・島内・帰港後の徒歩・車の帰路を分割。海上移動には船便の公式URLを使い、海を渡る徒歩経路を生成しません。
- レストラン、物語、リンク集、持ち物、共有文、メタ情報、manifest、オフライン案内、ICSを同期。
- localStorageは mojiko:2026-11-13:v2: へ変更。旧v1と汎用キーを読み込まず、削除もしません。時刻が同じチェック項目も旧完了状態を引き継ぎません。
- SWキャッシュは mojiko-ganryujima-shiori-2026-11-13-v2。旧アプリキャッシュだけ削除し、旧画面を再読込。他アプリのキャッシュは保持。
- 「次の予定」は日本時間・表示中の旅程・未完了項目で判定。30秒ごと、チェック変更時、タブ復帰時に更新する既存機能を維持。
- ICSは日本時間09:00〜16:00（終了は努力目標）の1予定。既存UIDを保持しSEQUENCE:1へ更新、詳細に後続例を記載。CRLF・75オクテット以内のUTF-8折返しを維持。
- tools/fixtures/previous-trip-worker.js は変更前の11月13日v1 SWを更新検証用に保存。既存legacy-worker.jsとともに本番キャッシュに含めません。
