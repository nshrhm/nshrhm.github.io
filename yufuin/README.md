# 湯布院お泊りBBQ 旅のしおり

2026年11月7〜8日のAMBER Yufuin【Villa1】家族旅行用の静的Webしおりです。BBQは機材レンタルプラン。旅程の時刻は案です。

## 閲覧・印刷

- `index.html`：当日の集合、選択プラン、買い出し、観光。
- `links.html`：選択プランに対応するルート、公式情報、写真クレジット。
- `print.html`：選択中の旅程と買い出し表。チェック・数量メモも反映します。
- プラン・チェック・メモは**このブラウザだけ**に保存され、家族には自動共有されません。LINE共有文をコピーして貼り付けてください。メモの削除は専用ボタンから行います。
- JavaScriptが無効でも、生成済みのプランA・持ち物・リンク・印刷用本文は閲覧できます。

## 更新手順

Node.js 22以上とMakeを使います。サイトの実行に外部JavaScriptライブラリは不要です。

```sh
make build
make check
make serve
```

`make serve` の表示先は `http://127.0.0.1:8000/yufuin/` です。ポートは `PORT=8001 make serve` で変更できます。

1. `data.js` の旅程・持ち物・費用・確認日を変更します。`TRIP.updated` は内容更新日です。
2. レイアウトはHTMLと `styles.css`、共通の生成処理は `views.js` を編集します。HTMLの `generated:...` 区間と `data-trip` の本文は自動生成されるため直接変更しません。
3. `make build` でWeb・印刷の静的本文と `sw.js` を更新します。配信ファイルのハッシュからキャッシュ版を自動作成します。`sw.js` は直接編集せず、`tools/sw-template.js` を編集します。
4. `make check` と必要なブラウザ検証を実行します。生成漏れがあると `make check` は失敗します。
5. 公開時は生成済みHTML・JS・CSS・manifest・assetsを同じ変更で反映します。公開後のHTTP・ブラウザ検証はローカル検証とは別に行います。

`SHOPPING` の `id` と `legacyIndex` は変更・再利用しないでください。追加品は新しいIDを付け、`legacyIndex` は付けません。旧51項目のチェック・プラン・家族メモは初回に一度だけ引き継ぎます。

## オフラインと更新

HTTPS（ローカル検証ではlocalhost）で初回保存が完了すると、本文・写真・QRをオフラインで閲覧できます。Googleマップと外部リンクには通信が必要です。`file://` ではオフライン保存は利用できず、ブラウザ保存の挙動も環境に依存します。

新しい版はファイル一式の保存が成功してから「新しいしおりがあります」と通知します。「更新して再読込」で切り替え、チェックとメモを引き継ぎます。同じサイトを開いている別タブも新しい版へ再読込されます。別サイトのキャッシュは削除しません。更新UIを持たない旧v2からの初回移行だけは、新版保存後に自動で一度再読込します。

CSPは各HTMLのmetaで設定しています。スクリプトと写真は同一サイト、埋め込み地図は指定したGoogleドメインに限定。既存のインライン装飾用に `style-src 'unsafe-inline'` は残しています。metaでは指定できない `frame-ancestors` 等を設定したという主張はしません。

## ブラウザ検証

PlaywrightとChromiumが利用できる環境で実行します。検証用ツールだけで、本番依存はありません。

```sh
# 既存のPlaywrightを使う場合
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
CHROMIUM_EXECUTABLE=/absolute/path/to/chrome make check-browser
```

`playwright` がNodeから解決でき、対応ブラウザがインストール済みなら `make check-browser` だけでも実行できます。今回の確認環境はPlaywright 1.62.0 / Chromium 151です。

結果・スクリーンショット・印刷PDFは `/tmp/yufuin-verification/` に出力します（`AUDIT_DIR` で変更可）。テストは外部の埋め込み地図だけを代替し、ファイル配信・Service Worker・オフライン処理は実ブラウザで実行します。地図の実接続、iPhone実機、読み上げ、紙のQR読取りは別途確認する層です。

## 写真・情報の根拠

写真はWikimedia Commonsの960px縮小版を同梱しています。作者・原典・ライセンス・加工内容は `links.html` と `LICENSES.md`、取得URL・寸法・SHA-256は `sources/photos.json` に記録しています。

同じ画像を再取得するには `node tools/fetch-photos.cjs` を実行します（curlとネット接続が必要）。記録されたハッシュと違う場合は停止します。写真の更新時は原典・ライセンスを確認し直してください。
